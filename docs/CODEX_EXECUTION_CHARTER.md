# 天明 ERP 精简执行章程

状态：A级执行规则

确认来源：老板于 2026-08-20 对统一总任务书及冲突建议的确认

适用范围：家庭开发、隔离 UAT、候选交付、工厂发布和所有子任务

## 1. 规则层级

1. 老板在当前任务中的最新明确规则；
2. `docs/TIANMING_ERP_MASTER_REQUIREMENTS.md`；
3. NAS 当前 A 级业务规则；
4. 当前任务卡；
5. 已人工验收的 B 级事实；
6. 旧任务、历史回执和旧代码实现；
7. AI 建议。

发现会改变数量、金额、状态、权限、客户范围、迁移链或现场动作的冲突时必须停止实施并确认。低风险且已有 A 级规则时可作明确记录后的合理推断。

## 2. 需求理解门禁

新的跨模块总任务第一阶段只允许读取、检索、审计、映射和冲突确认，不得改代码、迁移、数据库、正式系统或 Git。老板确认理解报告后，子任务不再反复全文理解总需求，只按 `CODEX_START.md` 路由读取相关章节。

每个子任务开始前固定：

- 现场问题和操作员可观察结果；
- 数量、状态、权限、客户范围、人工确认、幂等、事务、版本、审计和数据库不变量；
- 本轮不做的内容；
- 需要保护的历史回归；
- 家庭端与工厂端边界。

## 3. 任务和分支

- 一个任务 ID 对应一个最小可验证闭环、一个独立 worktree/分支和一份 NAS 回执。
- 从实时 `origin/factory-current-baseline` 建立 `codex/` 分支，不能从旧候选或脏工作区继续堆叠。
- 旧候选只能作为证据；合并前必须核对祖先、patch-id、迁移链、文件范围和当前正式实现。
- 不重复开发已正式等价整合的能力；暂停任务不计入活动交付，除非老板明确恢复。
- 本总任务内家庭候选完成验证后允许提交并推送，无需逐次再问；这不授权合并正式分支或工厂发布。

## 4. 多模型和文件所有权

- Sol：需求冲突、架构、任务依赖、风险和最终复核。
- Terra：跨文件业务逻辑、API、迁移、事务、幂等、库存和数量。
- Luna：边界清楚的 UI、CSS、打印样式、机械测试和只读审计。
- 使用最低足够能力；只有任务卡或老板明确要求时并行。
- 每个文件只能有一个写入负责人；数据库迁移和正式数据修复始终单负责人串行。
- 并行任务必须有独立 worktree、文件 allowlist、前置依赖和验收标准。

## 5. 数据和迁移安全

- 家庭端不得写或替换工厂正式数据库；只使用指定隔离副本及其复制品。
- 禁止把 `erp.db` 当历史订单源；`BoxDB20_REPRO` 只读；`legacy_ruida_*` 未经授权不刷新。
- 迁移任务必须读取三份迁移文档，先备份并验证，再在副本执行 upgrade → downgrade → upgrade。
- migration revision 必须唯一线性；旧候选同名 revision 必须重新编号，禁止双 head。
- 正式迁移、停服、重启、数据修复和历史回写必须由工厂端取得当次明确授权。
- 任何数量或成本都必须有来源、守恒关系、流水和可逆边界；禁止靠批量改数据掩盖代码错误。

## 6. 交互与确认

正常保存、新增、收料、打印、筛选、查询和正常地图移库不做二次确认。删除、作废、撤销、覆盖历史事实、批量正式数据修复、重复打印及实际成品高于理论时确认一次。取消、关闭、ESC 或遮罩不能执行操作；普通业务不要求填写原因。

## 7. 回归门禁

修复类任务先复现失败或建立失败用例。实现后至少验证：

- 正常路径和明确失败路径；
- 权限及客户范围；
- 数量换算与单位；
- 状态资格和乐观锁；
- 幂等同键重放、异载荷拒绝；
- 事务故障回滚和审计原子性；
- 历史冻结事实不被当前主档覆盖；
- 相邻旧 Bug 回归；
- 编译、构建、差异检查和唯一 Alembic head。

全量测试只在整合边界运行一次。浏览器验收只使用 Chrome；禁止 IAB 及 `browser.tabs.finalize(...)`。实体打印、真实手机和工厂屏幕只能标记为外部人工验收，不用自动测试冒充。

## 8. 构建与发布资产

前端源码、入口 HTML、构建 bundle 和测试必须形成闭环。提交前核对引用存在、旧 hash 无引用、无孤儿资源，并记录关键资产 SHA-256。禁止源码已更新但正式入口仍加载旧 bundle。

## 9. 回执和状态

每个任务在 NAS `04_开发记录\任务回执` 写独立回执，包含目标、分支、SHA、文件、测试、迁移、数据边界、历史回归、风险和人工验收入口。

状态严格区分：

- 开发验证通过；
- 候选已推送；
- 技术发布完成；
- 正式 ERP 人工验收完成。

未完成人工验收时统一写“开发验证通过，正式 ERP 人工验收待完成”。只有长期启动规则、正式基线、迁移链或跨端紧急事实变化时才更新全局交接索引。

## 10. 默认交付格式

最终回复只保留：摘要、验证结果、是否写入数据、知识库回写位置和下一步建议。不能只写“已完成”。环境没有提供真实 token 用量时必须说明不可获取，不得估算。
