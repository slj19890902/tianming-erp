# 天明 ERP Codex 精简启动入口

本文件只负责把当前任务路由到最小权威上下文。业务规则以 `docs/TIANMING_ERP_MASTER_REQUIREMENTS.md` 为唯一总索引，执行纪律以 `docs/CODEX_EXECUTION_CHARTER.md` 为准。

## 1. 固定启动顺序

1. 读取 NAS `Z:\sata1-18015598002\天明ERP知识库\AI_START.md`。
2. 读取当前任务卡；没有明确任务卡时停止写代码，先固定范围。
3. 按下表选择一个主模块上下文。
4. 只读取主模块上下文指向的总需求章节和执行章程小节。
5. 实时核对当前分支、工作区、远端正式基线、版本、Alembic heads、数据库路径和运行服务。
6. 用自己的话固定目标、成功条件、业务不变量、禁止范围及历史回归。
7. 用 `rg` 定位代码与测试，只读取命中的必要段落。

## 3. 升级读取条件

- 追查旧 Bug、候选、提交或 migration：在 `docs/CODEX_HANDOFF.md` 和 NAS `04_开发记录\任务回执` 中精确检索。
- 判断是否已上线或人工验收：只读取能力台账的对应标题段落，再核对当前 Git、代码、迁移和运行服务。
- 业务规则冲突：读取总需求对应章节和 NAS 当前规则原文，按证据等级处理。
- 迁移、发布或回退：完整读取三份迁移文档、当前任务卡和最近正式发布回执。
- 正式数据异常：先在指定隔离副本或正式库只读查询，任何修复写入另取授权。

禁止默认全文读取 `docs/CODEX_HANDOFF.md`、完整能力台账、长日志、CSV、原始聊天备份和大型单体前端。

## 4. 长对话重新定位

每完成一个阶段、切换任务或长对话后，只重读：

1. 本文件；
2. NAS `AI_START.md`；
3. 当前任务卡；
4. 一个主模块上下文；
5. 总需求和执行章程中被该上下文点名的小节。

任何 SHA、版本、migration、正式数据数量、端口和服务状态都必须实时读取。本文件不固化这些易变化事实。
