# 天明 ERP Codex 精简启动入口

本文件是每个任务的本地最小启动入口。完整历史仍保留在 `docs/CODEX_HANDOFF.md` 和 NAS 知识库，但默认不得全文载入。

## 1. 固定启动顺序

1. 读取 NAS：`Z:\sata1-18015598002\天明ERP知识库\AI_START.md`。
2. 读取当前任务卡；没有明确任务卡时停止写代码，先定位或创建任务范围。
3. 只选择一个主模块上下文：
   - 订单、报价、PDF、报料、来料、生产、送货：`docs/context/ORDER_FLOW.md`
   - 库存、货位、栈板、模具、拿货：`docs/context/WAREHOUSE.md`
   - 对账、开票、收款、成本：`docs/context/FINANCE.md`
   - 权限、版本、发布、备份、性能、审计：`docs/context/PLATFORM.md`
4. 执行只读状态快照：当前分支、工作区改动、最近提交、远端正式基线、Alembic heads。
5. 用自己的话写出：目标、成功条件、业务不变量、禁止修改范围、历史回归保护点。
6. 再用 `rg` 定位代码和测试，只读取命中的小段。

## 2. 升级读取条件

仅在下列情况定向读取长文档：

- 需要追查旧 Bug、历史候选、提交或 migration：在 `docs/CODEX_HANDOFF.md` 和 NAS `04_开发记录\任务回执` 中按精确关键词检索。
- 需要判断功能是否已上线、待验收或仅规划：读取能力台账中的对应标题段落，不全文读取。
- 业务规则冲突或证据等级不清：读取 NAS 证据规范和相关规则原文。
- 涉及迁移、正式发布或回退：完整读取三份迁移文档、相关发布纪律和本次任务回执。
- 涉及历史数据：重新核对数据库角色；不得把历史报告当作当前写入授权。

## 3. 不可变安全边界

- `Z:\sata1-18015598002\天明ERP知识库` 是唯一长期知识库。
- 家庭端只在工厂数据库副本上验证；工厂正式发布、迁移、重启和正式数据写入必须另行授权。
- `data\carton_erp.sqlite3`、`legacy_ruida_*`、`BoxDB20_REPRO`、`erp.db` 的角色不得混淆。
- `BoxDB20_REPRO` 仅作隔离权威源只读核对；`erp.db` 不是约四万历史订单来源。
- AI 只能推荐、提示、核对和生成草稿，不得替代人工确认正式业务事实。
- 工作区已有无关改动必须保留；未经授权不 commit、push、合并或迁移。

## 4. 防止旧 Bug 复发

每个改动至少完成以下检查：

1. 用任务编号、错误原文、接口、数据模型、业务单号、提交或 migration 搜索历史回执。
2. 区分“历史曾修复”“当前候选包含”“工厂正式已上线”“现场已验收”四种状态。
3. 把相关数量、状态、权限、幂等、事务、版本和数据库边界写成回归不变量。
4. 修复类任务先复现失败或补回归测试；新增功能补相邻旧 Bug 用例。
5. 修改后运行定向测试、相邻模块测试和差异检查；全量测试只在集成边界运行一次。
6. 任务回执列出本轮保护的历史回归，不能只写新增功能。

## 5. 上下文与输出预算

- 开发前固定全文资料不超过 4 份，建议总量不超过 40KB；超出时先用标题和 `rg` 缩小范围。
- 单次工具输出默认控制在约 4,000 Token；长日志、CSV 和测试详情写文件，只返回错误摘要和末尾统计。
- 默认单代理；禁止嵌套代理和把完整父线程复制给辅助代理。
- 长对话重新定位只重读本文件、`AI_START.md`、任务卡和一个主模块上下文。
- 完成时默认只汇报摘要、验证结果、是否写入数据、知识库回写位置和下一步建议。
