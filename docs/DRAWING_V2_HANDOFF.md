任务只在新订单冻结来源的同事务自动绑定：普通项核对当前产品版本及规范尺寸，组件核对冻结产品版本；订单专用图和组件冻结旧图继续优先。晚补历史任务不猜测最新图版。待料/待生产有效任务可明确选版并确认未下发后采用，追加审计事件，原绑定不变。任务状态不自动等于“未下发”。纸单、手机及重印读取固定版，保留既有数量、工序、报料/实收、权限、印版及单模具/库位体系。

新印刷原件类别 `private:drawing_originals/` 在图库标为 `purpose=print_artwork`，不参与旧默认工程图选择；旧附件继续兼容，不批量改名、迁移或删除。缓存基线另有两项随链路补验修复：订单逐行重算 PDF 匹配标志；新 BOM 冻结用途沿用已包含每套组件物理片数的来源值。没有回填历史快照或改变收货算法；合入工厂代码时保留现场已有同类修复。

## 环境与配置

沿用现有 FastAPI、SQLAlchemy、Alembic、Pillow、ReportLab 等环境，没有新增依赖。主 UAT 使用 `D:/纸箱厂erp软件搭建/.venv/Scripts/python.exe`；部分协作检查使用既有系统 Python 3.12。两者已核实 Pillow `12.2.0`、ReportLab `4.2.5`；前端方法检查使用已有 Node `20.12.2`。不同运行记录不能称为一次统一全量测试。

|配置|使用要求|
|---|---|
|`ERP_DATABASE_PATH`|明确指定当前批准的库；隔离开发始终指定新的隔离副本，不能依赖默认库路径。|
|`ERP_FILE_STORAGE_DIR`|明确指定隔离文件根；未来正式运行才指向获准的 NAS 根。V2 缺配置会报错，不静默回退本地目录。NAS 由 ERP 服务账号访问，客户端通过鉴权接口取文件。|
|`ERP_UPLOAD_TEMP_DIR`|沿用既有临时上传目录边界，不与正式图纸或备份混用。|
|`ERP_DRAWING_V2_ENABLED`|默认 `1`；设 `0` 停新编辑、上传、发布、自动新绑定及显式采用，已发布历史仍可读取、重印。|
|`ERP_DRAWING_TEXT_FONT_PATH`|可指定已有 `.ttf/.ttc`，TTC 使用索引 0；未配置仅取 `%WINDIR%/Fonts/simsun.ttc`。缺字体明确报错，不自动换字库。|

包内不分发系统字体。字体、渲染规则或字形结果变化后，现有草稿须重新保存核对；历史发布仍使用冻结资产。PDF 标题/说明采用原 ReportLab 字体流程，本机 Poppler 使用 SimSun 替代 STSong-Light；工厂查看器和打印机效果未验证。

更新后端代码、schema 或配置后需要重启 ERP 后端服务；更新 `static/index.html`、纸单页后刷新静态资源。这里的重启要求用于后续获准的运行环境，本轮没有重启正式应用。
