# 常用箱照片批量打包工具

## 作用

本工具把整批 `HEIC/HEIF/JPG/JPEG/PNG` 原图一次性转正、压缩并嵌入常用箱
Excel 的 J 列。它只生成新的 XLSX 和核对报告，不连接 ERP 数据库，也不会把
任何一行自动改成“新增”。

源 Excel 和源照片保持只读，不删除、不改名、不覆盖。

## 现场最短操作

1. 双击：
   `scripts\windows\start_product_photo_batch_tool.bat`
2. 依次选择：
   - 已登记样品信息的 Excel；
   - 整批照片文件夹；
   - 输出文件夹。
3. 历史照片若还是 `IMG_7655.HEIC` 这种名称，选择三列配对 CSV；
   若照片已按样品号命名，直接跳过 CSV。
4. 核对输出目录中的明细/异常报告。
5. 成功后按 `第001卷` 到最后一卷的顺序逐卷上传 ERP 预检。

## 三种明确配对方式

优先推荐给照片直接命名：

```text
YP001_图1.HEIC
YP001_图2.HEIC
```

也可在 Excel 的 J 列填写原文件名：

```text
IMG_7655.HEIC;IMG_7656.HEIC
```

历史照片较多时，可使用 `docs/templates/product_photo_mapping_template.csv`，
只填三列：

```text
样品号,照片1,照片2
YP001,IMG_7655.HEIC,IMG_7656.HEIC
YP002,IMG_7657.HEIC,无需
```

CSV 可直接使用 Excel 保存的 ANSI/GBK 中文编码，也可使用 UTF-8。第 4 列以后如有
客户编码等辅助资料，照片工具不会改写或导入，只读取前三列。

选择 CSV 后，以 CSV 中出现的样品号和照片文件名为本轮权威配对；它会替换对应行中
已有的预览图片。只有写入 CSV 的照片才算本轮配对；照片文件夹中未写入 CSV 的照片
视为尚未登记，直接忽略，不阻断本轮。明确只需一张图时，`照片2` 必须写 `无需`；
留空仍按漏填图2阻断。生成的 Excel 会自动在现场备注写入
`图片要求=1张（已确认）`，供 ERP 预检区分单图和漏图。

工具绝不按相邻文件或拍照顺序自动两两配对。

## 固定门禁

以下任一情况都会停止生成可导入文件，并输出异常报告：

- 双图款不足或超过两张，或单图款不是恰好一张；
- CSV 的 `照片2` 留空；只有明确写 `无需` 才允许单图；
- 样品号为空、重复或在 Excel 中不存在；
- 同一文件或相同 SHA-256 内容被重复分配；
- 文件缺失、损坏、伪造扩展名或像素尺寸异常；
- 未使用配对 CSV 时，照片文件夹中存在未归属的受支持图片；
- 图片不能准确锚定到对应 Excel 行的 J 列；
- 单卷超过 ERP 的 20MiB 绝对上限。

任何业务阻断都会在所选输出目录生成 `异常报告.csv`，不会再只显示空的
`report_path`。使用相同批次号重复运行时会生成 `_002`、`_003`，不会覆盖上一次报告。

## 压缩与分卷

- 最长边默认 `1600px`，JPEG 质量默认 `76`；
- 转正后清除 EXIF/GPS 等元数据；
- 已符合要求的 Excel 内嵌 JPEG 不重复压缩；
- 相同源文件使用输出目录内的 SHA-256 缓存；
- 每卷目标不超过 `16MiB`，最多 `200` 款/`400` 图；
- 同一款的一张或两张图永不跨卷；
- 每卷生成独立 SHA-256、样品清单和压缩明细。

当前 ERP 对每卷分别预检、分别提交事务，多卷不具备跨卷整体回滚。必须按卷号
顺序导入；前一卷失败时不得继续后一卷。

## 编码安全边界

手写型号可能是合作纸箱厂内部代码，客户用于送货单的正式 ERP 存货编码仍待确认。
工具只处理图片和 J 列，不复制、推断或覆盖以下字段：

- 手写/合作厂型号；
- ERP 存货编码；
- 客户料号；
- 系统 ID；
- 操作（新增/更新/不变）。

客户正式编码映射未确认前，生成文件只能用于整理和预检，不得正式导入。

## 命令行

```powershell
.\.venv_p122\Scripts\python.exe -X utf8 `
  .\scripts\prepare_product_photo_workbooks.py `
  --template "D:\待整理\常用箱登记表.xlsx" `
  --photos-dir "C:\Users\Administrator\Desktop\实物图" `
  --mapping "D:\待整理\照片配对.csv" `
  --output-dir "D:\待整理\ERP待上传"
```

使用配对 CSV 时，未写入 CSV 的照片默认忽略。只有未使用 CSV、且明确要处理照片目录
子集时，才需要 `--allow-unused`。
