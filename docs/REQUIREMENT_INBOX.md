# 天明 ERP 需求收件箱

更新时间：2026-07-24
用途：这是所有新需求的唯一登记入口。聊天只负责说明，最终状态以本文件和独立验收单为准。

## 使用规则

1. 新想法先登记为“收件箱”，不立即修改当前任务。
2. 同时最多一项处于“开发中”；切换前必须记录原任务恢复点。
3. 进入“开发中”前必须有 `docs/acceptance/REQ-编号.md`。
4. P0 只限工厂无法使用、数据错误扩大或明确安全故障。
5. “家庭UAT通过”不等于“工厂待发布”；必须先建立发布单并明确发布顺序。
6. 修改范围或验收标准时，先改验收单，再继续开发。
7. 用户发送新想法时只需写：`登记到需求收件箱：你的想法`；Codex 负责分配需求编号和写入本文件。

## 想法发送入口

- 普通功能想法：发给家里电脑上打开本项目的 Codex，使用“登记到需求收件箱”开头。
- 当前需求的验收反馈：写明对应 `REQ-编号`，记录进该需求的独立验收单。
- 工厂正在发生的停机、数据错误扩大或安全故障：先发给工厂 Codex 做只读诊断，同时把诊断摘要带回家里收件箱；没有明确授权时不得直接改正式系统。
- 聊天可以换，收件箱不能换；最终是否已经登记，以本文件出现需求编号为准。
