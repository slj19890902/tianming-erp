# UI Style Guide

## Current Direction

- Keep the existing ERP layout and information density.
- Avoid large structural redesigns in this baseline.
- Company info and delivery print should fit the current admin-focused style.

## Behavior Expectations

- Admin settings pages should be clear and compact.
- Print views should prioritize company identity information at the top.
- Error states should be concise and readable.

## Scope Boundary

- No global UI rewrite in this merge.
- No historical data display changes in this merge.
- No unrelated workflow redesigns in this merge.
