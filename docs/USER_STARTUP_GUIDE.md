# 天明 ERP 平时怎么打开

## 推荐方式

1. 双击桌面上的【打开天明ERP】。
2. 等几秒钟。
3. 系统会自动检查环境、升级数据库、启动 ERP，并打开网页。
4. 浏览器打开后就可以登录使用。

## 如果网页打不开怎么办

先不要自己乱改文件，按下面做：

1. 先再双击一次【打开天明ERP】。
2. 看黑色启动窗口里有没有中文提示。
3. 如果提示“Python 环境不存在”，把窗口截图发给管理员。
4. 如果提示“8000 端口被其他程序占用”，也把截图发给管理员。
5. 如果提示“ERP 启动失败”，把完整窗口截图发给管理员。

## 管理员怎么创建桌面快捷方式

运行：

```powershell
scripts/windows/install_desktop_shortcut.ps1
```

执行成功后，桌面会出现【打开天明ERP】。

## 管理员怎么设置开机自动启动

运行：

```powershell
scripts/windows/install_startup_task.ps1
```

设置成功后，电脑登录 Windows 后 ERP 会自动启动。
也可以理解成：开机登录后自动启动 ERP。

## 管理员怎么关闭 ERP

运行：

```text
scripts/windows/stop_erp.bat
```

如果系统正在运行，会先让你确认，再关闭 ERP。

## 注意事项

- 不要随便关掉黑色启动窗口。
- 如果已经打开 ERP，再双击一次也没关系，系统会先判断是否已经在运行。
- 如果设置了开机自启，电脑刚开机时先等一会儿再打开网页。
- ERP 数据库文件不要手动删除。
- GitHub 同步和 ERP 启动不是一回事。
