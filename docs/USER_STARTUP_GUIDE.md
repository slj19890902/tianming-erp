# ERP 启动使用说明

## 平时怎么打开 ERP

1. 先双击项目根目录里的 `start_erp.bat`。
2. 脚本会自动检查 ERP 是否已经在运行。
3. 如果还没启动，它会先做数据库准备，再打开浏览器。
4. 如果已经启动，它会直接打开网页，不会重复启动。

## 为什么浏览器不能自己启动 ERP

ERP 不是单独的网页文件，它需要先运行后端程序。
所以平时不要直接双击浏览器地址来当作启动方式。
正确方式是先运行 `start_erp.bat`，再进入网页操作。

## 如果启动失败，看哪里

如果双击后没起来，先看这个日志文件：

`logs\erp_startup.log`

如果提示端口被占用，也可以先执行停止脚本，再重新启动。

## 桌面快捷方式

如果想要桌面图标，请运行：

`scripts/windows/install_desktop_shortcut.ps1`

默认会创建一个英文名称的快捷方式：

`Open Tianming ERP.lnk`

## 开机自启与异常恢复

开机自启是可选的，不是必须项。

正式工厂环境启用健康守护后，会在开机和登录时自动启动；服务异常退出时每 20 秒检查一次，并通过同一受控启动入口恢复。发布维护期间守护会自动暂停，避免干扰受控停服。

安装或更新健康守护，请运行：

`scripts/windows/install_startup_task.ps1`

不要手动删除 `TianmingERP` 计划任务；若服务仍无法恢复，查看 `logs\erp_health_guard.log` 和 `logs\erp_startup.log`。

## 不要随便删除这些文件

以下文件不要手动删除：

- `.venv`
- `data\carton_erp.sqlite3`
- `logs`
- `data\backups`

如果这些文件被删了，ERP 可能无法正常启动或无法恢复数据。

## 常见检查顺序

1. 双击 `start_erp.bat`
2. 等网页自动打开
3. 登录 ERP
4. 检查首页是否正常
5. 检查订单、送货、对账页面是否能打开
