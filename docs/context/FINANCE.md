# 财务模块上下文路由

适用：月结对账、开票任务、发票记录、收款、客户账期、税局模板、成本和首页财务指标。

## 必读路由

1. 当前任务卡。
2. NAS 对账、开票、成本与加工费相关业务流程和模块设计的命中段落。
3. 对应客户案例、成功导入样例说明和最近任务回执。
4. 涉及金额口径时读取老板确认的 A 级规则原文，不从历史页面或示例猜测。

## 代码入口

- 财务 API、statement/invoice/payment 服务与模型
- 首页财务聚合接口
- 财务、对账、开票模板和权限专项测试

## 必须保护的历史回归

- 对账明细只来自有效且已确认回单，金额基于实际确认数量。
- 对账、开票任务、发票和收款是不同业务对象，不能用一个状态字段互相冒充。
- 税局模板只生成草稿；正式登录、上传、开具和结果确认由财务人工完成。
- 销方、客户税务资料、税率、税收编码、含税口径和舍入规则缺失时必须 fail-closed。
- 已冻结任务和历史发票不随客户资料修改回写。
- 无财务/成本权限的角色不得从页面、API、导出、日志或 AI 输出旁路读取金额。
- 首页待对账、待开票、待结款必须与目标页面复用同一资格和客户/月度口径。

## 最小验证

使用隔离匿名或授权副本核对数量×单价、税额、舍入、客户/月度归组、权限脱敏和状态前置条件；不得用修改正式数据来“修正”指标。
