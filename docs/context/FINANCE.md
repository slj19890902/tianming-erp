# 成本、对账与收款上下文路由

适用：材料成本、毛利、回单、月结对账、开票、收款和财务权限。

优先读取总需求：第6.13章、第7章、第16章，以及总任务中的轻财务边界。

必须保护：

- 销售金额和订单数量不因采购用途拆分改变；
- 理论材料成本与实际采购成本分别表达；
- 订单用途成本和片料库存成本按实际数量分摊，合计等于采购总成本；
- 实际采购价来自正式供应商报料/采购明细经授权确认的最终价格，并显式冻结单位、币种、税口径、税率、确认人与版本；
- 实际材质变化按收料行冻结的实际材质和有效价格重算，不用当前主档参考价覆盖历史冻结价格；
- 对账金额使用回单确认数量；未回单不得进入正式对账；
- 金额、税率、权限、版本、审计和事务保持原有门禁。

每条正式收料行冻结当时有效的价格和材质；发生收料后只能通过有原因、权限、版本和审计的受控更正动作调整。历史补差范围不清时停止实施，不得自行覆盖旧收料快照。
