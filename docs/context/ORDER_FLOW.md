# 订单主链上下文路由

适用：订单、报价、PDF、报料、采购、来料、生产、送货、回单、追溯。

优先读取总需求：第4、6、7、10、11、12、16、17章。

必须保护：

- 订单成品数量、纸板采购张数、拼版产出和片料张数不能混用；
- 正式采购单冻结后的供应商、材质、尺寸、压线、数量、价格和用途不能被主档静默覆盖；
- 客户范围、权限、状态、CAS、幂等、事务和审计；
- 普通来料与明确备库用途的例外边界；
- 一个订单明细一个持续存在的生产任务，重复打印不新建任务；
- 撤销必须先检查送货、库存、预占、生产和后续使用。

历史取证只按任务号、订单号、存货编码、API、模型、提交或 migration 检索，不全文读取交接档案。
