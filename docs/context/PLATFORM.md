# 平台、权限与交付上下文路由

适用：认证、RBAC、审计、版本、备份、发布、回退、性能、安全、通用 UI 和迁移链。

优先读取总需求：第2至5章、第14至15章、第18至19章；执行细节读取 `docs/CODEX_EXECUTION_CHARTER.md` 对应小节。

必须保护：

- 菜单隐藏不能替代后端权限和客户范围；直接 ID、搜索、统计、打印和导出同样受控；
- migration 唯一线性，正式迁移前备份并在副本完成往返演练；
- 家庭端候选推送不等于正式发布或人工验收；
- 性能和 UI 优化不能改变数量、金额、状态、权限、库存或财务资格；
- 前端源码、构建 bundle、入口 HTML 和测试必须闭合；
- 普通页面使用 Chrome 验证，禁止 IAB 和任何 finalize 清理；
- 敏感凭据、连接串、正式附件和无关客户数据不得进入日志、回执或提交。

发布类任务还要核对候选 SHA、正式基线、迁移 head、备份、运行配置、健康检查和回滚点。
