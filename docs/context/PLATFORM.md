# 平台与交付上下文路由

适用：认证、RBAC、审计、系统版本、备份、发布、回退、性能、安全、通用 UI 和迁移链。

## 必读路由

1. 当前任务卡。
2. NAS 开发、迁移与验收纪律及证据规范中的相关段落。
3. 相关发布/安全/性能任务回执。
4. 只有实际涉及 migration 时，完整读取 `docs/MIGRATION_PLAN.md`、`docs/MIGRATION_RUNBOOK.md`、`docs/MIGRATION_CHECKLIST.md`。

## 代码入口

- 认证、权限、审计、版本、启动和发布脚本
- Alembic migrations 与迁移专项测试
- 通用前端只按具体页面、函数、接口路径定位

## 必须保护的历史回归

- 菜单隐藏不能替代后端权限和客户范围门禁；直接 ID、搜索、统计、打印和导出同样受控。
- 密码、令牌、验证码、连接串和完整敏感附件不得进入日志、报告或模型上下文。
- migration revision 必须唯一线性；旧候选同名 revision 不得直接合并制造双 head。
- 正式迁移前备份并验证；先在副本 upgrade/downgrade/re-upgrade，正式动作另行授权。
- 系统版本只在需要外部验收时显示业务更新和验收步骤；技术回执仍保留完整证据。
- 发布、回退、停服、重启和正式基线更新不能由普通开发任务自动授权。
- 性能优化不得改变状态、权限、数量、财务或库存资格；必须做结果集合等价验证。

## 最小验证

运行权限成功/失败路径、旧会话撤销、敏感信息检查、唯一 Alembic head、差异检查和任务相关专项。发布类任务还要核对精确 SHA、备份、revision、运行配置、健康检查和回滚点。
