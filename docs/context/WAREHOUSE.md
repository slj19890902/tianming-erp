# 仓库、地图与模具上下文路由

适用：库存、片料、货位、栈板、移动、盘点、数字孪生、模具和位置标签。

优先读取总需求：第6.10至6.15章、第7.5章、第9章、第13章、第17章。

必须保护：

- 库存批次和流水是数量事实，地图只作空间投影；不得建立第二套数量账；
- 使用稳定 `location_id`，员工界面隐藏内部编码；
- 唯一标准栈板尺寸为 1200×1000×150mm，源码、投影和构建资源必须共用同一事实；
- `FIN-001～003` 是同一个合并暂存区的视觉表达，不冒充三个独立正式库位；
- 片料优先进入现有半成品/原料暂存区；原料过多时才允许按受控现场规则临时使用成品区域；
- 正常移库只提交一次，写正式库存流水，支持整批和部分数量；
- 模具内部稳定 ID 不向员工展示；共享模具保持一个本体和多客户关联。

任何正式位置新增、分拆、迁移或历史批次修复都必须在工厂端备份后单独授权。
