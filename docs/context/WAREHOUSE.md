# 仓库模块上下文路由

适用：原料/半成品/成品库存、预占、批次、流水、楼层、区域、货位、栈板、模具和手机拿货。

## 必读路由

1. 当前任务卡。
2. NAS `02_业务流程\库存抵扣与仓内流转.md` 或库存分层规则中的相关段落。
3. NAS `03_功能模块设计` 中仓库、货位、模具或拿货对应章节。
4. 按库存批次、库位码、订单明细、错误文字或任务编号检索任务回执。

## 代码入口

- `app/api/warehouse.py` 及库存/预占/流水服务
- `static/warehouse.html`：先按函数名、API 路径、区域码定位
- 库存、三楼、模具、拿货和生产消耗专项测试

## 必须保护的历史回归

- `inventory_lots` 是正式数量账；地图和栈板投影不得形成第二套可独立修改的数量。
- 客户专用、通用、原料、半成品、成品不得因界面相邻而混用。
- 保存草稿或打印不得扣库存；正式发货或确认动作才形成受控流水。
- 预占、释放、消耗和反向流水必须保持幂等、版本、事务和数量守恒。
- 未布局、待归位和无坐标位置不得伪造地图点，也不得自动成为入库、移位或拿货候选。
- 送货员的任务地图权限不得扩大为全仓查看权限。
- 正式数据库和家庭 UAT 副本必须分离，真实库存不得用旧快照或历史盘点自动升级。

## 最小验证

验证目标库存对象的前后余额、活动预占、流水、位置投影、客户范围和重复请求；涉及迁移时增加 upgrade/downgrade/re-upgrade 与完整性检查。
