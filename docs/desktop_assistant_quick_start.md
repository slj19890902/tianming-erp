# 天明ERP助手：按电脑用途操作

新版界面有两个页签。先选这台电脑的用途，按钮右侧会解释它做什么。

## 工厂正在使用的电脑

第一次使用助手：如果尚未接入数据，展开“遇到问题／其他设置”，选择“首次接入原ERP数据”，按提示先停原ERP再复制。已经接入的电脑不用重复做。

1. 点“设置每天自动备份”，选择共享文件夹并设置恢复密码。恢复密码不是ERP登录密码，请在电脑以外另存一份。
2. 点“现在备份一次”，完成后检查顶部最近成功备份时间。
3. 平时点“打开ERP”处理业务；有新版本时点“更新ERP”，助手会先备份。

晚上11点自动备份时，电脑须开机、账号保持登录，锁屏可以；关机或注销不能执行。

## 工厂电脑损坏后，由备用新电脑接替

先连接存放备份的共享盘，准备原恢复密码。新电脑使用空安装目录。

1. “从备份取回数据”：选择最新的完整备份文件（.tmbackup），输入工厂电脑备份时设置的恢复密码。
2. “设置本机访问地址”：填写新电脑的IPv4地址，可在Windows设置的网络属性中查看。仅新电脑自己使用时可填127.0.0.1。
3. “打开ERP并核对”：登录后检查最近订单、库存和附件。数据只能恢复到所选备份的时间。
4. “设置每天自动备份”：新电脑重新设置共享盘和恢复密码，再到工厂电脑页做一次备份。核对打印机后开始使用。

只是提前准备备用机时，恢复后核对即可，不要和原工厂电脑同时正式录单。恢复操作不会覆盖已有安装的数据。

## 其他按钮什么时候用

点“遇到问题／其他设置”查看，再次点击可以返回操作步骤。

- 继续上次未完成的更新：更新断电或中断后使用。
- 退回上一个程序版本：新版无法使用时使用；不会把业务数据退回旧日期。
- 首次接入原ERP数据：原工厂电脑第一次接入助手时使用。
- 修改本机访问地址：电脑地址改变后调整访问入口。
- 设置AI密钥（DeepSeek）：用于AI库存解读，不是恢复密码。

## 怎样换成新版助手界面

关闭旧助手窗口，运行本次新版TianmingERP-Setup.exe，选择原来的安装位置，确认更新已有助手。ERP服务不需因为更换助手而手动停止，业务数据和原配置会保留。仅刷新ERP网页或更新业务程序包，不会更换旧助手EXE。
