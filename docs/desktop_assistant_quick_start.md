# 天明ERP助手：按电脑用途操作

新版界面有两个页签。先选这台电脑的用途，按钮右侧会解释它做什么。

## 工厂正在使用的电脑

第一次只做两步：

1. 点“设置每天自动备份”，助手内会直接展开设置页。确认预填的NAS文件夹（也可粘贴完整路径），输入恢复密码并再次确认，点“保存并启用自动备份”。恢复密码至少12个字符。恢复密码不是ERP登录密码，请在电脑以外另存一份。可以使用网络地址或已挂载的NAS盘符；自动备份时保持相同Windows账号登录及NAS连接。
2. 等员工保存单据后，点“首次接入并启用”，选择原ERP整个文件夹（本机为`D:\纸箱厂erp软件搭建`，不要选择其中的`data`）。助手先检查，再暂停原ERP、复制数据、保存完整恢复备份并启动。助手自身须安装在独立的`D:\TianmingERP`等目录，不能放在原ERP里面。

以后日常操作：

- “启动并打开ERP”：停止时启动，运行时直接打开。
- “现在备份一次”：完整备份，结束后按原状态恢复服务。
- “备份后停止ERP”：备份成功后保持停服，所有员工暂时不能录单；再次使用时点启动。
- “更新ERP”：同步已发布的程序，自动校验、备份、停服、更新和启动。首次需要时选择包含`latest.json`的发布更新目录，以后会记住；它可以与备份目录不同。此处同步的是已发布程序，不合并两台电脑各自录入的业务数据。

关闭助手窗口不会停止ERP。晚上11点自动备份时，电脑须开机且账号保持登录，锁屏可以；人工点停服后，夜间任务不会擅自开机启用ERP。

首次接入过程中备份中断时，保持原ERP停止，修复共享盘后在其他设置点“完成首次接入”。原数据保留；不要同时启动两份ERP。接入成功后，原启动脚本和旧目录发布会明确拒绝，防止继续使用旧账。

## 工厂电脑损坏后，由备用新电脑接替

先连接存放备份的共享盘，准备原恢复密码。新电脑使用空安装目录。

1. “从备份取回数据”：选择最新的完整备份文件（.tmbackup），输入工厂电脑备份时设置的恢复密码。
2. “设置本机访问地址”：填写新电脑的IPv4地址，可在Windows设置的网络属性中查看。仅新电脑自己使用时可填127.0.0.1。
3. “打开ERP并核对”：登录后检查最近订单、库存和附件。数据只能恢复到所选备份的时间。
4. “设置每天自动备份”：新电脑重新设置共享盘和恢复密码，再到工厂电脑页做一次备份。核对打印机后开始使用。

只是提前准备备用机时，恢复后核对即可，不要和原工厂电脑同时正式录单。恢复操作不会覆盖已有安装的数据。

## 其他按钮什么时候用

点“遇到问题／其他设置”查看，再次点击可以返回操作步骤。

- 继续上次未完成的更新：更新断电或中断后使用。
- 退回上一个程序版本：新版无法使用时使用；不会把业务数据退回旧日期。
- 完成首次接入：数据已复制但完整备份中断时，修复共享盘后继续。
- 修改本机访问地址：电脑地址改变后调整访问入口。
- 设置AI密钥（DeepSeek）：用于AI库存解读，不是恢复密码。

## 怎样换成新版助手界面

窗口标题中的“助手 v0.22.380”表示助手自身版本；接入后，页面状态中的“ERP程序”单独显示业务程序版本。更新ERP程序不会自动更换助手EXE。首次接入若提示安装包比原ERP旧，请用当前完整安装器更新实际安装目录后再试，以免使用旧页面。

378修复了首次接入时Windows阻止调用维护脚本的问题，保留原ERP进程身份和备份检查。此前Z盘备份设置修复也包含在内。备份设置点击后直接出现目录和两个密码输入框；已有恢复密码时两栏留空可继续使用，保存失败保留原设置。看到“自动备份已设置”后，再点击首次接入。

380把目录检查提前到停服之前。开发依赖和历史发布演练副本不重复搬入新系统，原目录中的文件保留。正式数据库、附件和运行配置仍须完整核对；遇到业务目录链接时会给出具体位置，不要删除链接。首次完整备份需要复制及校验文件，请等待助手显示接入完成。

关闭旧助手窗口，运行本次新版TianmingERP-Setup.exe，选择原来的安装位置，确认更新已有助手。ERP服务不需因为更换助手而手动停止，业务数据和原配置会保留。仅刷新ERP网页或更新业务程序包，不会更换旧助手EXE。
