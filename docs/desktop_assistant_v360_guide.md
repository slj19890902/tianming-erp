# 天明 ERP 助手正式安装包 v360

本安装包绑定正式代码 `5e4113ac631a553aa13e33ff28820e74c301c72f`、程序版本 `v0.22.360` 和数据库版本 `sq29v8x9z91`，使用原固定发布身份签名，包含离线运行环境和中文 OCR 模型。

## 当前电脑更新

1. 打开现有“天明ERP助手”，确认 NAS 与恢复口令已设置，并立即做一次完整备份。
2. 点击“检查并更新”。助手会校验签名、再次完整备份；本版数据库 revision 不变，只更新程序。
3. 在 OpenAI 安全窗口完成组织和项目选择并创建密钥；不要把密钥发到聊天中。
4. 回到天明ERP助手，点击“设置AI密钥”，连续输入两次。助手会用 Windows 当前用户加密保存并按原运行状态重载 ERP。
5. 打开库存助手，确认显示“AI库存经营解读已启用”，生成一次解读并人工核对依据。

## 备用电脑安装

1. 运行 `TianmingERP-Setup.exe`，选择有足够空间的空目录。
2. 从桌面打开“天明ERP助手”，选择“从NAS恢复到本机空安装”，选择经过验证的 `.tmbackup` 完整恢复包并在本机输入恢复口令。
3. 设置该电脑固定局域网 IPv4，确认没有其他 ERP 占用端口，再打开 ERP。
4. 重新设置 NAS、每天 23 点备份和 AI 密钥。AI 密钥绑定 Windows 用户，不随 NAS 备份迁移。
5. 做一次完整备份，再从另一台设备人工检查登录、邮箱收单、订单、仓库、库存助手、送货单和实体打印。
