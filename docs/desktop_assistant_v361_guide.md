# 天明 ERP 助手 v361 更新说明

v361 更新包绑定正式代码 `56908b2cfffa9a5127a8c40ca781dc78b53b1d90`、程序版本 `v0.22.361` 和数据库版本 `sr30v8x9z92`。原 v360 安装器继续作为安装入口，打开助手后会从 NAS 获取 v361 签名更新包。

## 当前电脑更新

1. 打开“天明ERP助手”，先做一次完整备份。
2. 点击“检查并更新”。助手会验证固定发布签名、再次备份、在隔离副本演练迁移，再更新程序和正式数据库。
3. 更新后打开 ERP，进入“系统备份 → 系统版本”，确认版本为 `v0.22.361`、数据库版本为 `sr30v8x9z92`。
4. 进入“订单 → 邮箱收单 → 邮箱设置”，确认自动读取已启用且间隔为 5 分钟。

## AI 密钥

OpenAI 密钥须在安全创建窗口选定组织和项目后创建，再由安装助手“设置AI密钥”写入本机。密钥由 Windows 当前用户加密，不进入数据库、日志、Git、更新包或 NAS 备份。不要通过聊天发送密钥。

## 备用电脑

1. 运行 `TianmingERP-Setup.exe`，选择空间充足的空目录。
2. 从 NAS 的经过验证完整备份恢复；在备用电脑本机输入恢复口令。
3. 设置固定局域网 IPv4，确认端口没有被其他 ERP 占用。
4. 在备用电脑重新设置 NAS、23 点备份和 AI 密钥。
5. 人工检查登录、邮箱收单、订单、仓库、库存助手、送货单和实体打印。
