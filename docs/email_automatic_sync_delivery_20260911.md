# 126 邮箱自动收单正式交付

## 已上线行为

正式 ERP `v0.22.361` 已启用 `sz_tmbz@126.com` 收件箱自动读取，默认间隔 5 分钟。管理员可在“订单 → 邮箱收单 → 邮箱设置”暂停、恢复或调整为 1 至 60 分钟，并查看最近开始、完成、结果、新增数、剩余数和错误原因。

自动任务只读访问收件箱。它不会把邮件标为已读，不移动、不删除、不发送邮件，也不会自动创建订单。PDF 作为主要订单附件进入待核对工作台；管理员核对并保存后才形成 ERP 订单。

## 管理员人工验收

1. 打开邮箱设置，确认“自动读取”已启用、间隔为 5 分钟、最近结果为成功。
2. 向收件箱发送一封新的 PDF 订单，等待最多 5 分钟。
3. 确认新邮件进入待核对列表，126 邮箱中的原邮件没有被标已读、移动或删除。
4. 打开 PDF 核对内容；不点击确认保存时，ERP 不应新增订单。
