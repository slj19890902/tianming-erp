# v0.20.8 常用箱编辑页面优化

验收时间：2026-06-28 22:19

## 本次更新解决了什么

- 常用箱编辑页面重新按六行整理，桌面上能放在一行的字段不再散开。
- 长、宽、高按整数毫米显示，不再出现多余的 `.0`；单价仍保留小数。
- 材质供应商、层数、楞型和材质放在同一行。
- 报料长宽、压线类型、A1 推荐计算和报料备注在桌面宽度下保持同一行。
- 生产工艺可以同时选择粘贴、打钉、模切、双拼和其他。
- 印刷内容改为清楚的下拉选项。选择“无印刷”时不显示图纸区域；选择有印刷时显示图纸上传和版本历史。
- 图纸历史按时间倒序显示，最新一版有“最新”标记；继续保留旧版本。
- 备注单独放在最后一行。

## 为什么有用

- 文员录入常用箱时不用来回找字段，页面更紧凑。
- 尺寸统一按毫米整数查看，减少把毫米看成厘米或误读小数的情况。
- 生产工艺和印刷类型变成固定选项，后续下单和生产查看更一致。
- 新图纸不会覆盖旧图纸，出现版本争议时可以回看历史记录。

## 数据处理说明

- 本轮没有执行历史迁移。
- 本轮没有修改数据库结构。
- 本轮没有批量修改历史产品、订单或图纸。
- 生产工艺复用现有字段，保存为逗号分隔文字。
- 印刷类型复用现有印刷内容字段。
- 图纸上传继续使用现有图纸版本表和接口。
- 旧的非标准工艺或印刷文字在人工重新选择前会保留。

## 页面排列

1. 第一行：客户、存货编码、产品名称、箱型。
2. 第二行：长、宽、高、默认单价。
3. 第三行：材质供应商、层数、楞型、材质。
4. 第四行：报料长宽、压线类型及 A1 推荐计算、报料备注。
5. 第五行：生产工艺、印刷内容、上传图纸、图纸版本历史。
6. 第六行：备注。

## 使用时要注意什么

- 无印刷的常用箱不会显示图纸区域，这是正常行为。
- 有印刷但暂时没有图纸时仍可保存，之后再补传图纸。
- 上传新图纸会增加一个版本，不会覆盖以前的图纸。
- 删除图纸版本仍需管理员确认。

## 我需要打开哪些页面检查

1. 打开“常用箱与材质”，选择一个客户。
2. 点击任一常用箱的“编辑”。
3. 检查六行字段顺序和长宽高整数显示。
4. 勾选多个生产工艺，再取消，确认操作清楚。
5. 将印刷内容切换为“无印刷”，确认图纸区域隐藏。
6. 切换为“单色印刷”或“多色印刷”，确认图纸上传和版本历史显示。
7. 对有图纸的常用箱上传一份新图纸，保存后重新打开，确认新旧版本都在。
