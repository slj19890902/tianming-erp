# 日常操作说明（简明版）

## 2026-06-21 订单编号与分组使用说明

1. 新建订单时，系统会自动生成 `TM...` 主系统单号，前端只做预览，最终以保存结果为准。
2. 同一张订单下，每条明细都会自动生成 `TM...-001 / -002 / -003` 这样的明细系统单号。
3. 订单管理默认先看“客户单号”，不是先看系统单号。
4. 系统单号默认隐藏；需要看时，请展开订单或打开详情。
5. 同一客户、同一客户单号会自动分成一组；不同客户即使客户单号一样，也不会混在一起。
6. 如果客户单号没填，系统不会把不同订单强行合并。
7. 搜索时可以搜：
   - 客户名称
   - 客户单号
   - `TM` 主系统单号
   - 明细系统单号
   - 产品编码
   - 产品名称

## 2026-06-20 使用提示补充

1. 历史订单日常统一显示为 `TM...` 编号，直接搜 `TM` 即可。
2. 新建订单必须先选客户，再选常用箱和填写数量。
3. 如果保存失败，应看到中文提示；如再次出现原始报错文本，先停止录单并反馈。
4. 查看客户常用箱时，先点客户，右侧应显示该客户产品，不应跳到材质字典。

## 一、每天开机后怎么确认系统能用

1. 打开 ERP 首页
2. 看能不能正常登录
3. 看首页数字有没有正常显示
4. 随便打开一张订单，看能不能打开详情

## 二、每天录单前要注意什么

1. 先确认客户选对
2. 先确认产品、规格、材质对不对
3. 先确认交货日期有没有填错

## 三、订单录错怎么办

- 小地方填错：打开订单修改后保存
- 整张单录错：先问管理员，优先作废，不要乱删历史单

## 四、不要随便删除什么

1. 历史订单
2. `TM` 订单
3. 客户资料
4. 产品资料
5. 备份文件

## 五、怎么搜索历史订单

1. 打开订单列表
2. 在搜索框输入订单号
3. 历史导入单可直接搜 `TM`
4. 也可以按客户筛选

## 六、怎么查客户订单

1. 打开订单列表
2. 选择客户名称
3. 查看该客户下面的订单

## 七、怎么查看详情

1. 在订单列表找到订单
2. 点“查看详情”
3. 看客户、日期、数量、金额、产品信息

## 八、系统卡住时先怎么处理

1. 刷新页面
2. 重新登录
3. 关掉浏览器再打开

## 九、什么时候需要联系技术人员

1. 页面一直打不开
2. 登录失败
3. 金额明显不对
4. 系统一直报错
5. 不小心动了不该动的数据

## 十、每天下班前要检查什么

1. 今天新增的订单能不能查到
2. 重要客户订单有没有录对
3. 测试订单有没有处理掉
4. 管理员有没有做当天备份

## 十一、账号和密码要特别注意

1. 不要继续使用默认密码或大家共用同一个密码。
2. 管理员、财务、销售、车间最好各用各的账号。
3. 第一次拿到账号后先改密码。
4. 密码不要写在电脑桌面便签上。
5. 如果发现别人也知道自己的密码，要马上联系管理员重置。

## 十二、正式试用开始前

1. 先确认管理员已经给每个岗位发了正式密码。
2. 先确认不是默认密码、也不是大家共用同一个密码。
3. 如果还没正式改密，不要开始日常录单。

## 十三、管理员要先完成的事

1. 在本机用隐藏输入方式给四个岗位设置正式密码。
2. 不要把密码写进文档、微信群、桌面文本或 Excel。
3. 改密完成后，再开始安排岗位试用。

## 十四、试用第一天先做什么

1. 四个岗位各自先登录一次，确认自己能进入系统。
2. 如果哪个账号进不去，不要共用别人账号，先找管理员。

## 十五、备份现在怎么保留

1. 系统现在默认只保留最近 5 个常规备份。
2. 关键迁移备份和最终归档备份不会自动删除。
3. 如果你看到带 `FINAL`、`MIGRATION`、`tianhua_batch`、`legacy_refresh` 的备份，不要自己删除。
4. 想清理备份前，先让管理员或技术人员先做 dry-run 检查。
