## 一、抽查原则

1. 不要动天华历史迁移数据
2. 测试请使用专门测试客户或专门测试订单号
3. 建议测试订单号：`TEST-YYYYMMDD-001`
4. 建议测试客户：`系统测试客户-勿对账`

## 二、检查清单

- [ ] 登录
- [ ] 首页能正常打开
- [ ] 订单列表能正常打开
- [ ] 搜索测试订单号
- [ ] 搜索 `TM`
- [ ] 按客户筛选
- [ ] 打开 1 张历史订单详情
- [ ] 新增 1 张测试订单
- [ ] 修改测试订单
- [ ] 作废或删除测试订单（仅测试单）
- [ ] 财务账号查看财务页面
- [ ] 车间账号查看车间/来料页面
- [ ] 手机来料页面检查
- [ ] 打印或导出 1 次
- [ ] 退出登录
- [ ] 重新登录

## 三、测试数据处理建议

1. 只处理测试客户、测试订单
2. 优先把测试订单作废
3. 如果必须删除，只删测试订单
4. 绝对不要处理 `TM` 历史订单
5. 测试完成后再次搜索确认测试数据已清理

## 四、账号与权限试用前补充

1. 先让管理员本地设置正式交接密码，不要使用文档中的默认口令。
2. 首次试用建议准备四类账号：
   - 管理员
   - 财务
   - 销售
   - 车间
3. 每个账号先登录一次，确认会跳转到各自可见菜单范围。
4. 不要用管理员账号代替所有岗位做试用。
5. 如果发现“能看到不该看的菜单”或“能点开不该开的页面”，先记录，再联系技术处理。

## 五、正式交接密码完成后再做

1. 先确认四个角色都已拿到各自正式密码。
2. 先逐个验证一次登录、退出、重新登录。
3. 如果某个角色第一次登录就提示必须改密，按现场规则执行。
4. 如果还没有完成正式改密，不要开始实际人员试用。

## 六、现场管理员执行前

1. 先运行交互式改密脚本，不要把密码告诉无关人员。
2. 改密完成后，再把各自账号交给对应岗位。
3. 未拿到正式密码前，不要开始角色试用。

## 七、试用开始时第一步

1. 管理员、财务、销售、车间四个岗位各自先登录一次。
2. 登录成功后立即退出，再重新登录一次。
3. 如果有任何账号登录失败，先停止后续试用并联系技术处理。
