补充发现：

- 当前后端登录代码只接受 bcrypt 密码校验。
- 这表示该账号同时存在弱口令风险和旧密码格式风险。

## 二、风险说明

正式使用前，默认密码或弱密码必须处理。

主要风险：

1. 密码过弱，容易被猜到。
2. 多人共用账号，无法追责。
3. 旧密码格式与现有认证逻辑不一致，可能导致现场登录异常。
4. 目前缺少正式的财务账号、销售账号，不适合直接上线分岗使用。

## 三、推荐账号体系

建议至少准备 4 类正式账号：

### 1. 管理员账号

- `admin_main`
- `admin_backup`

### 2. 财务账号

- `finance01`

### 3. 销售 / 文员账号

- `sales01`
- `sales02`

### 4. 车间 / 来料账号

- `workshop01`

## 四、建议权限范围

### 管理员

- 全部菜单
- 系统备份
- 用户管理
- 密码重置

### 财务

- 查看订单、客户、送货、回单
- 操作对账、开票、收款
- 不允许系统设置、用户管理、删除订单

### 销售 / 文员

- 客户、产品、订单、报料、送货
- 不允许系统备份、用户管理、财务结算确认

### 车间 / 来料

- 查看订单
- 使用来料页面
- 不允许财务页面、系统设置、客户资料修改

## 五、正式使用前必须执行

1. 管理员现场重置 `admin` 密码。
2. 管理员现场重置 `workshop` 密码，并改成当前系统支持的新密码格式。
3. 新建正式 `finance`、`sales` 账号。
4. 每个账号使用单独密码，不允许共用。
5. 密码长度至少 10 位，且必须同时包含字母和数字。
