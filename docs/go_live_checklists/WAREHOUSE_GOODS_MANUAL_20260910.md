# 仓库片料人工维护与反向匹配

当前任务：老板要求完善仓库成品、半成品、原材料人工操作及供应商白面纸，并从原材料查找所有客户常用箱的适用报料尺寸。

候选版本：v0.22.330；迁移：rt10v8x9z67 → rv10v8x9z70。

## 操作入口

1. 仓库地图 → 点普通货位 → 添加货物。默认成品，继续按客户存货编码操作；半成品、原材料直接填名称、纸板长宽、层数楞型、实际张数和日期。
2. 原材料默认通用；适用范围可选指定客户并多选。半成品填写加工状态，可选模具；模切、压线、印刷片料逐款勾选已确认可用产品。
3. 标签丢失选未知或目测估计并填写线索；已经核实才选择供应商材质。白面纸在供应商材质编辑里勾选，两种面纸颜色不可互用。
4. 批次 → 匹配产品，先看报料尺寸完全一致，再看需裁切候选。可筛客户、存货编码；保存候选不会预占库存。
5. 匹配区 → 人工维护适用客户、材质和加工资料，追加第二家客户或改为通用。保存不改数量、原始材质、成本及历史单据。已预占批次须先处理预占才能修改用途。
6. 核实材质、加工及用途后勾选生产用途确认，进入订单人工抵扣候选；半成品先于原材料。裁切建议不能绕过正式尺寸、楞型、换算和压线校验。
