# v0.22.331 仓库片料操作

- 客户选择框支持名称、拼音、首字母；勾选框和名称同排。
- 新增半成品/原材料输入材质代码，可直接选供应商条目。页面显示当前平方价及按尺寸折算的单张价、合计；入库时冻结该批价格。自由填写未选报价时不猜测成本。
- 主数据 → 供应商 → 纸板材质维护 → 基础纸种代码：颜色位于克重与等级/说明之间，默认瓦楞色，白纸代码改为白色后保存。组合材质首位纸种决定面纸颜色。
- 无需额外勾选材质核对或允许替代。白色与瓦楞色不互用；同颜色半成品可换材质，白色不同代码的原材料同规格可用。尺寸、楞型、加工与适用客户规则继续执行。
- 原有批次用途编辑不追改原入库价格。实际收货采购事实仍通过原收料流程维护。

验证：后端针对性回归、拼音真实运行库测试、前端类型检查与构建；安装版 Chrome 无头模式隔离组件验证客户每行28px、勾选框16px、名称间距8px。未向正式库新增测试库存。
