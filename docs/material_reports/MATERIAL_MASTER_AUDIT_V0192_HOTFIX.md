## 10. 数据库字段缺失问题

当前 `materials` 表缺少以下字段，导致特殊材质只能从文本字段推断，无法精确查询：

| 缺失字段 | 说明 |
|---------|------|
| `material_origin` | 进口 / 国产 |
| `paper_type` | 牛卡 / 白卡 / 瓦纸 / 芯纸 |
| `material_grade` | AAA / AA / A / B |
| `is_special_material` | 布尔值，标记是否为特殊材质 |

**建议：** 后续 v0.19.3 增加上述四个字段，本轮不做 migration。

## 11. 处理建议

1. **修正 R=17000 错误（17条）：** 不可直接导入，必须先将 R=17000 改为 R=100，需人工逐条复核后操作。
2. **补充嘉林亿特价单：** 上传照片后再核对，特价版本代码目前无法验证。
3. **核对鸣朋子单：** 鸣朋 BA/EB 五层和三层组合报价单中的代码需逐条确认是否已在总库中。
4. **处理缺失代码：** 11 个两表均无的代码，需确认是否已失效/变更/从未录入。
5. **处理 ERP 转换表专属代码：** 5 个仅在 ERP 转换表的代码，不能直接用于材质主表。
6. **先修 xlsx 再导入：** 建议修正 xlsx 后导出 CSV，不直接使用当前 xlsx。
