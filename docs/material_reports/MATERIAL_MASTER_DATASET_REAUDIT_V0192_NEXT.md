## 9. 同克重不同供应商检查 / 跨供应商同代码

- **跨供应商同材质代码：0 组**。三家供应商代码命名体系各自独立，无重叠。
- **同层数 + 同逐层克重组合、不同供应商：0 组**。逐层克重（含五层第一芯纸 /
  瓦楞里纸 / 第二芯纸细分）使得跨供应商的完整克重元组几乎不重合。
  → 直接按「克重完全相同」跨供应商比价的可行组合极少，比价仍需结合纸种 / 等级 / 国产进口判断。

## 11. 比价风险提示

1. **同克重但纸种不同**（如 俄卡 vs 普通牛卡、白卡 vs 牛卡）→ 不能直接比价。
2. **同克重但进口 / 国产不同**（如 进口木浆牛卡 vs 国产牛卡）→ 不能直接比价。
3. **同克重但等级不同**（如 AAA 级 vs A 级）→ 不能直接比价。
4. 跨供应商完整克重元组重合度为 0，跨供应商比价应基于「面纸/里纸主克重 +
   纸种类别 + 等级 + 国产进口」综合判断，由人工确认，系统只提示不自动换算。
