## 解除门禁所需输入

由工厂端重新执行正式周度 UAT 导出，把同一次生成的数据库快照、manifest、manifest SHA 和运行态正式地图放入 NAS。新包至少应声明：

- source Git SHA 不早于 `25f479c65511687860e732f92aa3a617660da7d1`；
- 数据库 revision 不早于 `jk69v8x9z58`（当前代码 head 为 `jl70v8x9z59`）；
- 数据库 `integrity_check=ok`、外键违规为 0、SHA-256 与大小通过；
- 包内运行态正式地图与正式数据库策略/plan 的 `published_map_revision` 一致；
- 地图草稿只作为受保护的存在性事实记录，不作为 P1-147 坐标权威或导出输入。
