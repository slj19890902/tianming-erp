## 未匹配原因分类

1. **款号混入“编码 / 产品描述”**：最主要原因。对未匹配款号取斜杠前缀后，同客户下可唯一命中27,431条；另有2条变成多匹配，2,870条仍无匹配。
2. **编码规范差异**：NFKC全角半角转换并统一大小写后，仅新增唯一匹配3条，同时产生2条多匹配。
3. **分隔符差异**：移除空格、横线、斜线、点号等后新增候选168条，但整体产生309条多匹配，风险高。
4. **空款号**：55条，无法通过编码规则匹配。
5. **主数据缺失或编码完全不同**：在“斜杠前缀”候选之外仍有约2,870条。
6. **尺寸候选**：同客户长宽高唯一候选12,313条，但尺寸不是产品身份键，只能用于提示；材质和产品名称字段不足以进一步形成唯一可靠匹配。

首尾空格不是主要原因：原始精确与去首尾空格后的统计完全一致。

## 清洗恢复与人工处理预估

| 规则层级 | 结果 | 自动化建议 |
|---|---:|---|
| 去首尾空格 | 新增0 | 安全，但无收益 |
| NFKC + 大小写统一 | 新增唯一3；多匹配2 | 安全预处理，但仍要求唯一 |
| 去常见分隔符 | 新增候选168；多匹配升至309 | 不自动，仅候选提示 |
| 取斜杠前编码 | 唯一候选27,431；多匹配2 | 高价值，需抽样验证后才能自动 |
| 同客户长宽高 | 唯一候选12,313 | 风险高，仅候选提示 |
| 长宽高 + 材质 | 0 | 当前产品材质文本不足 |
| 产品名称 + 规格 | 0 | 当前legacy产品名称字段不足 |

- 严格保守口径：仅NFKC/大小写可安全恢复3条，仍需人工处理约30,301条。
- 若“斜杠前编码”经专项抽样确认并限定为同客户唯一产品，可候选恢复27,431条，剩余约2,873条需人工处理。
- 本轮不应用任何增强规则。

## 产品匹配增强规则建议

### 安全规则

- 去首尾空格。
- NFKC全角转半角。
- 英文字母统一大小写。
- 每一步都必须限定同一客户且最终唯一匹配。

### 需评审后才能自动

- 对明确格式 `编码 / 描述` 提取斜杠前编码。收益很高，但需验证编码前缀不会代表旧版、组合品或费用项。

### 只能做候选提示

- 删除横线、斜线、点号等分隔符。
- 产品名称 + 规格。
- 长宽高。
- 材质。
- 上述字段组合的模糊相似度匹配。

这些规则可能把不同版次、不同印刷、不同材质或费用项错误合并，不能自动落库。

## 风险点

- 最大缺口集中在一个客户，错误规则可能批量污染大量历史订单。
- 斜杠前缀规则覆盖高，但尚未完成逐产品人工抽样，不应立即用于全量。
- 尺寸相同不代表产品相同，印刷、材质和工艺可能不同。
- 费用类款号（模具费、制版费、加工费）不应映射为普通纸箱产品。
- 本轮副本测试只验证已唯一匹配产品的多明细订单，不代表未匹配产品已解决。
