# 库存与物料台账

## 模块目标

提供基础库存可见性与手工核验边界，不把库存模块当主状态引擎。

## 当前真实业务规则

- 成品库存单位和物理尺寸需保持一致。
- 来料入库不应自动生成半成品库存。
- 预占结构建立后先在候选链路中严格验证。

## 主要数据来源

- `app/api/warehouse.py`
- 库存流水与批次服务

## 关键不变量

- 未确认前不扣减库存。
- `inventory_lots` 是正式数量账。

## 高风险修改

- 数量守恒规则
- 预占/释放事务一致性
