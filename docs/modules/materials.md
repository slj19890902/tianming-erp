# 报料与采购材料（非完整采购系统）

## 模块目标

只管理订单是否已报料、是否已到料，支持生产前可执行性判断。

## 当前真实业务规则

- 报料页面核心目标是状态确认，不做供应商财务结算。
- `legacy_*` 与 `erp.db` 不参与历史订单的正式来源判断。
- 已确认的报料建议不应自动覆盖人工修订。

## 主要数据来源

- `app/api/requisition.py`
- 订单明细与材料字段（订单上下文）

## 关键不变量

- 未报料订单不能直接跳到材料已到。
- 已到料数量必须可追溯到对应订单。

## 高风险修改

- 报料状态跳转规则
- 报料数量与订单数量的单位口径
- 材质/楞型字段回填链路

## 已知问题

- 报料数量异常需要按订单链路逐条复核。
