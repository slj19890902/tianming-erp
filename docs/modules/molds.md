# 模具

## 模块目标

管理模具/刀模基础信息与库存位置关系，支持纸箱厂后续上架、维修和可视化管理。

## 当前真实业务规则

- 模具是仓库地图的基础资源，不与订单财务金额形成一对一核算。
- 模具状态变更要可追溯，不因送货流程默认回填。

## 主要数据来源

- 仓库/模具相关数据库表
- 仓库 API 与前端库存视图

## 关键不变量

- 模具生命周期以状态和版本为准。
- 模具位置、可用性与实际库存位点一致。

## 高风险修改

- 模具主数据与仓库位点映射联动
- 模具批量状态回写
- 模具历史与现有订单流程混写

## 已知问题

- 与地图几何共享路径时，局部模式切换后显示一致性仍需观察。
