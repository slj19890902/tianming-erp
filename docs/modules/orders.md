# 订单 / 报价 / 送货主链

## 模块目标

让订单从报价到对账的状态流转可追踪、可回放、可验证。

## 当前真实业务规则

- 未收料不得显示“已可生产”。
- 回单确认是对账前置。
- 对账金额以回单确认数量为准。
- 已删除/作废记录不得触发新业务状态。

## 主要数据来源

- `app/api/orders.py`
- `app/api/requisition.py`
- `app/services/order_pdf_import.py`

## 关键不变量

- 同一客户下同一订单组不能并发混淆状态。
- 单位换算必须保持 `pieces_per_box` 的历史含义不被重解释。
- 送货与回单状态是明细级别链路，不得用单一订单头直接覆盖。

## 高风险修改

- 订单状态机重排
- 报价转单/常用箱快照字段变更
- 跨接口事务边界改写

## 已知问题

- PDF 草稿与正式单据边界仍需分离。
