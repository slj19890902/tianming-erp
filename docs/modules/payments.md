# 收款（payments）

## 模块目标
- 记录“已对账应收款项”的收款状态及实际收款动作，避免与开票/对账状态混用。

## 收款事实
- 收款动作以已开票且已对账的金额项为基础。
- 实收金额与对应对账单/客户口径进行绑定确认。

## 客户维度
- 客户分组是收款核对与催收优先级的基础。
- 仍以“客户 + 月份 + 对账单状态”作为人工复核主视图。

## 与已对账、已开票、未收款关系
- 对账未完成：禁止进入收款动作。
- 已对账未开票：默认禁止自动认定收款闭环。
- 已开票未收款：需明确“未收款”状态保留追踪。

## 高风险修改
- 误将对账完成与收款完成解耦，导致财务状态提前关闭。
- 未与客户维度联动导致催收、对账残留重复。

## 当前尚未完成的业务模型
- 收款确认策略（例如部分收款、预收、分批入账）未有统一口径，当前不在本阶段引入会计级规则。
