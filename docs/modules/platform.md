# 平台与发布（高风险边界）

## 模块目标

管理版本、权限、迁移、发布与回退的最低一致性。

## 当前真实业务规则

- 迁移需备份与复盘。
- migration revision 不得出现并行主干头。
- 发布动作不在普通 Bug 闭环内擅自执行。

## 主要数据来源

- 认证/RBAC/API 网关相关服务
- Alembic 迁移链与发布脚本

## 关键不变量

- 权限校验以后端为准，前端菜单仅为入口。
- 备份、重启、回退要有可追溯记录。
