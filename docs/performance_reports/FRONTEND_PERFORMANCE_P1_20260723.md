## 二、已完成的最小闭环

### 1. 运行依赖本地化

首页不再从公网 CDN 加载运行时，改用仓库内固定版本：

- Vue `3.5.40`
- Axios `1.18.1`
- pinyin-pro `3.26.0`

版本、来源、SHA-256 和许可证记录在 `static/vendor/README.md`。本地 vendor 响应使用一年 immutable 缓存。

### 2. 登录后按当前模块取数

删除登录后的 `loadBase()` 全模块预加载。登录或刷新时只读取当前页面所需接口：

- 首页：身份、首页概览、KPI
- 客户：客户列表
- 常用箱：客户选项、常用箱、材质、模具
- 订单：客户选项、订单列表
- 其他模块进入时再加载各自数据

这一步没有改变页面入口、权限或业务数据口径。

### 3. 短时页面缓存

- 已访问页面缓存时间为 30 秒。
- 30 秒内切回模块不重复发起同一页面加载请求。
- 顶部“刷新”始终使当前页面缓存失效并重新取数。
- 登出或身份失效时清空缓存、取消未完成请求和搜索定时器。

### 4. 搜索防抖与旧请求取消

- 客户、常用箱和订单搜索输入使用 300ms 防抖。
- 新搜索发起时使用 `AbortController` 取消同列表的旧请求。
- 客户、常用箱、材质和订单列表均接入“只保留最新请求”门禁。
- 首次客户列表仍限制为每页 25 条。

### 5. 服务端性能观测

新增只记录方法、路径、状态码和耗时的性能中间件：

- 所有响应包含 `Server-Timing: app;dur=...`。
- `/api/` 超过阈值时记录 `slow_api` 日志。
- 不记录 URL 查询值、请求体、响应体、账号或业务字段。
- 默认阈值 500ms，可通过 `ERP_SLOW_REQUEST_MS` 调整。
