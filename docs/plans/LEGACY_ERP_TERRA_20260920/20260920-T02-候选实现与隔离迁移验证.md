## 实现结果

- 新增来源主记录和来源行映射；直接 PDF 以签名内容哈希识别来源，邮件以服务器附件 ID 识别发生并复核内容哈希。
- 同一来源、同一规范化业务载荷只映射一张订单；跨设备、跨账号或更换操作键重试返回原订单。来源相同而客户、载荷或原订单状态不满足恢复条件时返回 409。

- PDF 前端显示“同单号新来源待确认”，说明会新建独立订单，并提供“查看原订单”入口；没有强制重复开关。
