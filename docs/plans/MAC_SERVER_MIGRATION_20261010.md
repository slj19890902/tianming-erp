## 4. 已发现的跨平台阻塞，不能省略

1. `desktop_assistant/manager.py` 的锁使用msvcrt，发布包要求runtime/python.exe，链接和进程维护使用Windows机制；`windows.py` 用计划任务。必须做Mac服务/更新/备份适配，保留单写锁、签名、公钥、schema/reader、备份验证和回退拒绝门禁，不能直接绕过Manager启动后称正式迁移完成。
2. `app/services/email_intake.py:protect` 在非Windows明确拒绝；备份密码、AI提供者及发布签名私钥同样用DPAPI绑定原用户。仅复制密文无法使用。旧Windows用户仍能解密时做受控加密重封装/凭据重录，并验证Mac身份能读；绝不把明文凭据放普通ZIP、日志、命令参数或Git。不能擦旧机后才发现无法解密。
3. 绝对Windows附件路径在Mac不能按本机Path直接解析。`desktop_assistant/attachments.py` 的现有重定位只覆盖已知PDF训练样本字段；必须扫描全部持久路径，使用Windows路径语义生成可审计映射。仅在新机副本更新必要路径，保存原值与映射，附件内容SHA不变；不批量替换所有文本中的D盘/Z盘字符串。
4. 中文合同默认找C:\Windows\Fonts；Mac需配置合法可用的中文字体并验证合同、报料、送货及标签无方框、错位或分页变化。PDF/OCR原生依赖、模型、ODBC等按真实使用情况验证，不假设Windows环境目录可复用。
5. 正式数据保留Mac本地SSD；NAS掉线不得导致切换到空库或另建库。服务采用专用低权限账号与launchd，不能依赖Codex对话、终端窗口或用户手动登录后的临时进程。
6. 所有导入、邮箱轮询、计划任务在家庭恢复预演中禁用外部写入/发信/重复收单；最终切换后单端启用。安全门禁不能因为Mac测试工具不兼容而删除。

依据：Apple建议后台脚本由[launchd管理](https://support.apple.com/en-ca/guide/terminal/apdc6c1077b-5d5d-4d35-9c19-60f2397b2369/mac)；Microsoft说明[DPAPI通常绑定原用户和电脑](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)；SQLite说明[网络文件系统访问的风险](https://www.sqlite.org/useovernet.html)及[一致性备份方式](https://www.sqlite.org/backup.html)。本机代码已验证上述依赖存在；Mac适配尚未实现/验证。
