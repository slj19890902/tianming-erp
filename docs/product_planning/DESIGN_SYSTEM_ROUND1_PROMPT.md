# 纸箱厂 ERP UI 设计系统 · 第一轮提示词（可直接粘贴）

## 这一轮要你产出什么

1. 先产出一套 **UI 规范展示页（设计系统 / design token）**：颜色语义、字号（标准 + 大字/长辈两档）、间距、按钮、输入框、表格行高、状态标签样例。
2. 规范定好后，紧接着出 **3 个 PC 高频页面高保真**：订单列表+订单详情/开单、送货/出货、登录+首页工作台。
3. 每个页面同时给「标准模式」和「大字/长辈模式」，并在页面上带一个**切换开关**演示两种密度（要求可切换、可记忆）。

## 范围约束

- 端：本轮只做**电脑端 PC**（给老板/管理员、销售/跟单、财务用）。手机端来料放第二轮。
- 角色：老板/管理员、销售/跟单、财务。车间多为只读、送货/收料是手机端，本轮不展开。
- 语言：**中文界面 + 真实纸箱厂示例数据**。
- 大字模式要求：正文 ≥16px、关键数字 20–24px、按钮 ≥44px、输入框 ≥46px、表格行高 54–60px；禁止低对比浅灰小字；允许放大页面。
- 状态必须有文字（不能只靠颜色），同一状态跨页面同色，金额类数字右对齐。

## 状态颜色语义（固定）

- 待处理/待发货/待回单/待对账：橙色
- 进行中/已发货/生产中：蓝色
- 已完成/回单已确认/已结算：绿色
- 财务/对账/开票：紫或深蓝
- 人工确认字段：黄色背景或黄描边
- 异常/超长/数量不一致：红色或高对比黄
- 危险操作（删除/取消发货）：红色，二次确认，不常驻主视觉

## 订单关键字段（按重要度）

- 列表必看：客户名 / 客户单号 / 产品名称 / 纸箱规格(长×宽×高) / 材质楞型 / 数量 / 已送数量 / 交期 / 状态
- 详情/开单：存货编码(料号) / 明细系统单号 / 纸板长宽(mm) / 压线尺寸 / 层数 / 客户单价 / 销售金额 / 预估纸板成本 / 预估毛利 / 图纸 / 生产备注
- 权限敏感（车间不可见）：单价 / 金额 / 成本 / 毛利

## 送货页要点（本轮重点之一）

统一状态时间轴：待发货 → 已发货 →（已签收/已对账由回单、对账推导，不写入送货状态）。按钮规则：
- 待发货行：编辑 / 删除 / 确认发货并打印
- 已发货行：补打 / 确认回单 / 取消发货（红色二次确认；取消会回滚订单已送数量，已有回单或已对账时被拒绝）

## 不要做

不要科技大屏/暗黑/玻璃拟态/花哨渐变；不要弹窗套弹窗（复杂表单用右侧抽屉或整页步骤）；不要把所有字段平铺；不要把成本利润塞进对账页。
