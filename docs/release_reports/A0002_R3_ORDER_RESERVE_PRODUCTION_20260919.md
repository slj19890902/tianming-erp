# A-0002-R3 订单余料受控转产回执

日期：2026-09-19  
候选版本：v0.22.458
数据库迁移：无

## 结果

冻结采购用途收料产生的订单余料已接入现有“生产与成品 → 待安排”事务链。系统只识别已发布、`semi_finished_reserve`、整张订单来源且仍关联原半成品批次的收料；普通订单用途、BOM组件、未冻结或身份不完整的来源不会进入。

安排生产继续使用原收料明细作为任务外键，预占和完工直接作用于原余料批次。目标产品固定为来源订单明细的同客户有效普通产品，开数和每箱片数读取采购用途冻结快照。完工沿用库存版本、幂等、位置发布、成本继承、客户范围、角色、审计和安全撤销机制，没有新增平行库存或伪造补库采购。

## 隔离证据

- 订单 500、采购 600、分两次各收 300 后，原订单自动形成 500 只成品，余 100 张进入待安排。
- 安排 60 张后原批次为可用 40、预占 60；同操作重放不重复预占，异载荷重放被拒绝。
- 完工 60 只后原批次为可用 40、预占 0、已耗 60；产出为来源订单同款产品并继承片料单位成本。
- 后续修改当前产品的每箱片数不会改写冻结换算，本次仍按冻结的 1 张产 1 只执行。
- 产出未被使用时安全撤销，原批次恢复为可用 100、已耗 0，产出批次关闭；撤销重放不重复恢复。
- 完工耗源期间，原收料冲正继续被 `RESERVE_INVENTORY_ALREADY_USED` 拦截；客户范围为空时列表不泄露该来源。
