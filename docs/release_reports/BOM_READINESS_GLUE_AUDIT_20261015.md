## 三、员工操作方案

1. **正常盘点**：选真实产品，输入数量、日期、位置、备注后保存。系统自动形成该类型适用的主档/BOM/成本快照；已有完整资料不再让员工准备系统依据。
2. **单独子件后组套**：按真实子件分别盘点。父件显示可组套数，点击组套完成并入库，系统一次事务完成扣子件、成品、成本、流水与审计，自动防重。没有第二套“凭据确认”操作。
3. **待完善**：显示具体编码和字段，点“修改该子件”或“修改BOM”进已有编辑页；保留原表单和上级未保存修改，保存后重查。实际缺料/预占/位置/历史批次问题分别显示数量和批次原因，不把它们写成无从处理的资料待完善。
4. **二次粘合**：在原工艺区勾选或取消。改到不适用箱型时自动移除二次粘合、就地提示，仍只保存一次；勾选时同步必要工艺依赖。已冻结订单和旧批次不改写。

类型边界：纯组套父件无独立纸板尺寸/材质要求；有真实本体的自制/外购父件仍需本体；按子件交付的组合按子件出入；旧明确parent_delivery保留真实父件库存。类型由保存的真实合同决定，不能靠补假尺寸/虚构消耗取得通过。
