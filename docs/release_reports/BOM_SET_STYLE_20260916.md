## 方案与实施

- 新增常用箱箱型“BOM组合（组套成品）”，复用 assembled / expand_children / parent 多级BOM合同，不新增一套库存机制。单位套、整套计价、父件交付，父件不单独报纸板，不要求材质、规格或加工资料；标签可选，每张数量以套计。
- 父件与子件配方一次原子保存；空配方、非法比例、跨客户、循环和版本门禁保持。新建父件无需先保存空壳才能添加子件。合法已保存组套配置显示父件资料完善；子件自身仍按对应生产/外购资料校验。
- 例如205每套3长+4短，在其上级纸箱内仍填写每箱5套，不能把15长20短填成一套205。只有实物插合确认后才扣子件、继承来源成本并产生真实成套库存。到料或配齐本身不等于组装完成。
- 不批量转换旧虚拟分存或旧旁路组套，保留受控转换保护。不改写历史订单冻结配方、正式库存、位置、价格或地图/草稿。
