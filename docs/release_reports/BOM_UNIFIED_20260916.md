# BOM全链路统一 — v0.22.442候选

## 已实现规则

| 场景 | 常用箱 | 库存/执行 |
|---|---|---|
| 自制纸箱本体＋子件 | 保留A1等实际箱型、尺寸、材质、开料；来源自制 | 本体和成套状态分开；组装才扣子件 |
| 无本体组套 | BOM组合，零件组装，单位套 | 不要求父件纸板尺寸；按消耗子件计成本 |
| 外购整件 | 外购，未设组装消耗 | 收料成为完整外购库存 |
| 外购本体＋子件 | 外购，逐项组装消耗 | 收料仅本体，不能直接当成套发货 |
| 随货子件 | 关系随货交付 | 保留独立库存；发货时按冻结关系扣除，不计入组装消耗 |
| 子件独立订单 | 子件仍为真实产品，有自己的箱型/开料 | 按该产品独立订单处理；关系属于父件BOM行，不全局锁成子件 |
| 已成套盘点 | 完整成品/独立子件 | 按当前本体＋消耗子件参考成本冻结；不重复扣子件 |
| 未组装本体盘点 | 仅本体，尚未装入子件 | 独立身份、自己的成本；只抵扣自身报料，附件需求不消失 |
| 零件余料 | 子件独立批次和位置 | 未预占部分仍是库存；实际组装确认前不虚增成套 |
| 取消/撤销 | 原业务入口 | 恢复原来源与预占；有未撤销下游、移库或不符流水时保留保护 |

人工沿用每人每小时50套默认，可在常用箱组合BOM的组装人工调整；人工与材料分别冻结，不把标准人工冒充实际工资。开料只换算每张产出，BOM每父件用量不重复乘开料数量。

## 边界

无migration；正式地图、草稿、旧配方、历史订单、数量、价格不批量改写。未组装本体以既有批次冻结身份保存，旧无标记库存不自动重分类。旧配方切换仍需实物兼容核验，不能将未组装本体当完整成品交接；不取消任何数量/客户/版本/成本证据门禁。

## 管理员最短验收

1. 常用箱选择真实箱型；BOM每行设置组装消耗/随货交付及每父件数量。
2. 盘点已有实物时区分完整成套与仅本体；有订单后在待组套核对数量、位置，实际装好再确认。
3. 实际发货时核对成套和随货子件扣库；不要为验收新增、重复收料或组装。
