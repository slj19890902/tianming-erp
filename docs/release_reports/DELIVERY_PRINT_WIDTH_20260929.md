现场为另一台电脑的EPSON SK820，非本机Cumtenn。两张照片分别是YL-20260929-001和GLR-20260929-002，数量后列和页脚同侧截断。旧实现以含孔边的241mm纸宽作为页面排版宽，215mm正文居中后右边缘达到227.996mm，检查只对比该纸框，未约束设备可输出范围。数量旁竖线为后续单价/金额或备注列边界，并非应删的单独装饰线。实际设备驱动报告、纸型和缩放尚未实机读取，不把照片推断冒充精确硬件测量。
