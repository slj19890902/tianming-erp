# 常用箱参数化图纸工作台

来源：老板2026-09-30“按照你的推荐方案执行升级优化”，批准方案见NAS `04_开发记录/任务回执/20260930-常用箱参数化图纸升级规划.md`。任务卡 `docs/tasks/DRAWING_WORKBENCH_20260930.md`。本报告首次提交为候选状态，正式结果在发布后追加。

## 实现

- 常用箱图纸入口新增全屏工作台，左侧模板/主尺寸/局部参数，中间二维展开与三维折叠，右侧发布版/BOM。说明默认折叠。
- 支持衬板、单片开槽箱A1/0201、既有定制内衬、开槽隔板、纯BOM组合。点选标注或线段定位对应参数，独立覆盖/恢复随动、撤销重做、缩放和旋转。保存中继续编辑保留后续改动，过期草稿须核对版本。
- 图形与折叠共用真实面片/铰链；隔板生成实际槽口闭合轮廓，可改每槽位置，禁止重叠和越界。图号、版次、纸厚可以编辑。
- BOM按产品ID和真实用量展开，子件有独立图纸/模具身份；每个实例可修改三维坐标和角度。发布冻结子件release及当时BOM，不从同编码猜身份，不从最新主档重写旧发布版。返回子件上级时保留装配草稿。
- 实体发布版导出工程PDF、SVG、1:1 PDF及毫米单位分层DXF；1:1含100mm标尺。纯BOM不生成虚假的1×1刀版，输出装配清单，实体子件分别导出。
- 旧印刷对象、附件、纸厚、编号、历史发布与订单/生产采用关系保留。内/外尺寸参考未经实际加工补偿不允许直接作为刀线发布。
