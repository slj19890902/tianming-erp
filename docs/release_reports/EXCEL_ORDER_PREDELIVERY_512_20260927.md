# v0.22.512 Excel 订单、预送货、缺货判断与找货路线

## 交付范围

- “导入订单”同时接收 PDF、xls、xlsx；原 PDF 解析与天华图片预送货保持原入口和兼容合同。
- 新增研光、光洋 Excel 预送货。文件只形成识别批次和待发货草稿，不自动创建订单、不自动扣库、不自动报料。
- 预送货按正式库存事实显示“仓库可拿、半成品待加工、材料已收待生产、材料在途、需订材料、待核对订单”。订单剩余数量不再冒充成品库存。
- 每个 Excel 原行保留文件哈希、工作表、原始行号和业务指纹；同一文件重复导入被拒绝。
- 找货路线读取最新已发布地图的正式位置坐标，跨货架采用确定性最短路径改进并在生成拿货单时冻结路线版本；不写地图、不猜造通道。
- A4 找货单压缩为员工需要的“顺序、存货编码/型号、货架层格、拿取数量、实拿”，不再堆叠产品名称和内部说明。

## 保存与安全门禁

- xls/xlsx 只读解析，拒绝宏、公式、外部链接、伪扩展名和异常压缩包；不调用 Excel/COM。
- 导入订单没有客户订单号时不能保存，提示人工对照原订单补齐；产品缺报料尺寸、供应商材质等主数据时仍逐行阻止并指出缺项。
- 发货确认仍由既有事务、预占、版本、幂等和审计接口执行；本次预送货预览不会改变订单、库存、采购或发货状态。
- 客户范围和权限保持；未经认证的订单、预送货、库存及路线接口继续返回 401。

## 隔离验证

- 四个用户实样只读解析：研光预送货 42 行/7895，研光订单 42 行/7895，光洋预送货 21 行/18224，研光订单 37 行/7120。
- Excel 解析、预送货 API、天华黄金回归、多图片批次、路线、A4 找货单、来源身份与邮件 PDF 队列定向测试通过。
- 数据库迁移新增 Excel 来源追溯、预送货多订单分配和路线快照字段；正式发布必须由助手完成最新正式库备份、隔离迁移演练、唯一 head、完整性和外键检查。

## 管理员人工验收

1. 在“导入订单”分别上传现有 PDF 与研光 Excel；Excel 无客户订单号时应提示补填，补齐后才能保存。
2. 在预送货切换“天华图片”和“研光 / 光洋 Excel”；确认天华旧流程不变，Excel 能看到仓库位置、数量和缺口分类。
3. 选择多货架货物生成找货单；核对路线顺序和正式地图实际通道是否一致，并以现场确认作为路线配置调整依据。
4. 打印一张 A4 找货单，确认员工能按货架、层、格、编码和数量完成拿货。

按既定规则不自动点击正式页面；实体打印与现场路线由管理员发布后验收。
