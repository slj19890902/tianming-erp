## 原因与修改

外购包材区原“客户规格”是 `external_packaging_specification_summary` 的只读摘要；真正可编辑、可保存且优先用于客户送货的 `customer_specification` 放在上方另一处“客户规格原文”。两处名称相近、取值不同，包材区不能直接维护送货规格。

现在外购包材区统一为“客户规格（同步客户送货单）”可编辑框，上方重复入口对外购产品隐藏。原常用箱保存流程同时保存该字段，重开回显。未单独填写时显示并随外购规格更新；直接编辑后使用保存的客户文字；可一键恢复随外购规格更新或明确留空。打开表单本身不冻结自动默认值。

复用既有产品版本、权限和审计协议以及 `delivery_specification` / `delivery_current_presentation`；同客户稳定产品ID的正常送货预览读取最新保存文字，已有送货单刷新也同步，原冻结版保留。采购实物规格、采购比例、历史出库数量、单价、金额、库存、成本和预占均不改。无DDL，唯一 head `ew1020em`。
