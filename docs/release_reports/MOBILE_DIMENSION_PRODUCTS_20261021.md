## 行为

手机原查询入口（/mobile/erp.html#lookup）的“查询 → 按尺寸查实存 / 找产品 / 取用”同时提供实存批次与相近产品档案。纸箱长宽高完整时，以产品主档实际尺寸按原方向逐轴比较，默认每边±10mm，可选20/50mm；精确优先，最大轴差、总差、客户/编码/ID稳定排序后分页。产品档案显示编码（前导零保留）、客户、名称、实际尺寸、逐轴差、实存状态及已有工程图纸。候选供人工辨认，不能证明实物归属；无虚构数量、位置或取用入口。

老板追加的手机输入布局已合入：长宽高并排三列，每项最多5位数字并弹出数字键盘；纸板只显示长宽两列。原每轴接近/等于/大于等于/小于等于条件保留。
