# 手机添加货物保存后返回当前货架 / 区域 v0.22.535

状态：技术发布完成，待管理员真实手机人工验收。

## 目标和修复

手机从货架或栈板货位进入添加页，成品、半成品、原材料保存成功后，自动回到当前货架正视图或当前栈板所在区域，并高亮原货位。顶部返回按钮同样保留当前货位。使用稳定 location_id，由正式地图数据恢复真实货架和区域。

旧逻辑保存后只重新读取添加页；看地图在没有 lot_id 时不传 location_id，返回原区域也刻意丢弃货位，造成无法恢复货架。现在使用 focus_only 返回模式，地图先恢复货架展开和格位高亮，不自动打开货物详情，也不触发空货位自动进入添加页。普通查货、点击货位、批次标签仍沿用原详情路径。

只有保存请求明确成功才返回；保存失败或网络结果不确定时保留表单、原幂等请求和重试锁定。页面跳转失败与保存失败分开提示，不把已确认的入库变成未知写入。已有库存归位 / 移货、半成品 / 原材料回调共用返回逻辑；不改请求内容、数量、版本、权限、事务或客户范围。旧缓存文档先刷新到兼容版再加载新运行脚本。
