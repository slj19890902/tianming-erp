# 模具标签编辑、解绑与组合查询 v0.22.522

状态：技术发布完成，待管理员人工验收。

## 范围与结果

- 编辑模具时实时预览标签，可保存标签专用身份、产品名称、报料尺寸、一开几和备注；清空专用值恢复自动内容。预览与新打印共用渲染器，文字超出可用空间时明确提示，禁止静默裁切。
- 首行左侧位置、右侧一开几；二维码 15×15 mm，正文保留独立空间。新打印采用 p1-119-v1；历史打印仍使用原冻结快照。
- 80011946 对应同一实体模具 242，两个有效常用箱的报料长宽分别为 772×336、876×336。旧逻辑因尺寸不一致显示“待完善”，并重复拼接 APS4 和产品编码。新标签去重展示真实尺寸，可按模具覆盖显示文字，不改产品尺寸。
- 编辑区直接列出已绑定常用箱并提供解绑；解绑沿用现有版本、审计和事务契约。解绑刷新保留未保存标签、客户和位置草稿；网络结果不明时先只读核对，不重复提交 DELETE。
- 新增与编辑均允许两个主标签客户；关联客户仍遵守已绑定产品保护，需要移除客户时先解除对应常用箱关系。
- 查询覆盖模具名称、标签名、简称、位置、备注、客户名称/简称/代码和绑定产品编码/名称；同一关键词框支持空格分词，各词均须命中相关字段，独立筛选条件继续取交集，权限和分页保持。
