## 人工验收与回退边界

1. 仓库地图 → 区域规划 → 新增区域，用途选“模具” → 添加模具货架；按实物设置 A—E、层格和位置，保存并应用。
2. 点货架 → 点 A1 等格位 → 放入模具，搜索/扫码并勾选实物，确认归位；核对正视图、模具详情、移动及返回路径。
3. 先试打一张整架或格位标签及一张既有模具标签，用手机扫码核对位置和可读文字；再批量打印。

不要把照片中的产品编码无条件作为唯一模具身份：长短片、多块、共享模具和不清楚的编码需要逐个确认。现有照片标题不区分 B 架，同号按同一物理格处理。

回退应使用现有签名发布流程并先核对新格位使用状态；一旦实际创建/归位到新 MCELL 格位，不能用旧布局覆盖或恢复旧数据库来回退。保留业务数据，优先向前修复。
