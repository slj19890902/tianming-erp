# R05 统一待报料与采购来源候选

范围：继续老板授权的 R05；保留原 R01/R02、包 B、R06 和正式 v454 PDF 保存恢复修复。本文件不是正式发布回执或管理员验收结论。

## 行为

- 客户备库和纸板库存预警保存为待报料需求，不再保存即确认采购。外购包材继续走既有独立外购流程。
- 现有待报料分页包含补库；普通订单、BOM 和补库可同选，按供应商一单多行。补库规格在需求端核对后冻结；普通与 BOM 保留采购用途调整和后端校验。
- 新增严格二选一的采购来源关联，分别指向原补库明细或原 BOM 报料明细；不伪造销售订单、不另建库存账。普通订单沿用原来源。
- 收货沿用稳定 r/sr 明细身份，显示统一采购单号，数量/用途/成本继续进入原来源账。补库来源未采购时禁止收货。
- 来源快照、数量和操作人不可覆盖；同键不同内容拒绝。一个有效来源只能有一条有效采购关联；失败整批回滚。
- 采购打印读取来源冻结压线。未知方向等兼容条件不猜测合并为一行，来源仍逐条保留。新补库来源单不再作为独立正式采购单打印。
- 撤销采购先锁定状态并检查收货、生产和库存事实；未收货补库回到待报料，BOM 复用完整父件撤销门禁。有收货时拦截。查询/预览不预占或扣库存。
- 库存预警仅把已采购的补库计算为在途，未采购或撤销采购的需求不会冒充在途库存。
