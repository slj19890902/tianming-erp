# 客户资料、常用箱与历史入库整页显示修复 v0.22.570

日期：2026-10-08。任务：PAGE-CAPACITY-20261008。技术发布完成，管理员页面验收待进行。

## 原因与修复

基于正式 v0.22.569 / 11c4474b 核查：客户资料没有参与可视高度计算，并与其他视图共用 pageSize；历史入库沿用固定条数；常用箱首次测量结果被提前缓存，隐藏页重新显示时没有重新测量通知。因此首次进入、切换页面与重复点击可能使用不同条数。

三类列表现在分别保存每页容量，按实际表格、筛选区、分页区和可用高度计算；窗口、字号和缓存页重新显示时重新校准。相同布局下保留已测量行高，避免末页或较短记录使条数反复增长。超过一屏的记录继续分页，取消这些桌面列表的内层纵向滚动。常用箱客户选择列表使用独立容量。待收料编辑草稿的原分页行为保留。

仅变更桌面列表显示和必要的导航显示通知，保留查询、权限、客户范围及后台接口。长内容和大字模式实际可显示条数可能较少；窄屏行为未调整。
