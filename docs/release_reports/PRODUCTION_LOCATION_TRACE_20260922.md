# 完工库存归位追踪修复

2026-09-22，老板反馈待送成品选择存放库位后，完工历史仍显示“暂无当前库存”。本轮沿已授权生产升级修复并发布。

根因：普通归位/移位会拆出新批次并保留完工来源，原完工指向的批次可能归零；历史只读取原批次，遗漏新批次。此前页面还以订单“已送完”覆盖库存位置。

按真实 production_completion 来源读取全部现存批次，不按同产品猜测；按位置逐批显示余量，原始完工位置与改量/撤销的业务身份保持原样。支持部分与连续移库、冻结实存、多位置及已送完余货。没有实存才显示暂无当前库存；位置异常显示实存与核对原因，逻辑待归位明确登记位置，不冒充地图已放置。
