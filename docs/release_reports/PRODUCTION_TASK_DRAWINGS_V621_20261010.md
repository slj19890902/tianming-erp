## 原因与实现

- 当前完整任务单使用ProductionTaskPaper，未消费图纸字段；旧managed图只在独立附页显示，主卡右侧为空。补库卡原图纸字段全部为空；PDF不能直接用普通img显示。
- 完整任务单改为全宽客户/纸板/数量表，左侧工艺、右侧对应编码缩略图。单图40mm高、多图28mm高、68mm右栏，保持图像比例和原工艺字号。多图/多产品自动续半页，每组续页使用独立A4；未绘图产品不占空栏。另校验页脚安全间距，避免图纸盖住页码。
- 每个产品与真实BOM子件分别读取图纸。已绑定任务发布版结构图优先；订单附件、BOM冻结指针、有效补库采购快照按精确来源读取。缺冻结图纸时列出该产品保留的工程上传并标记“参考图”，不当成原任务冻结版。印刷素材目录不作为结构图纸。
- 图片和PDF通过有权限的预览接口输出等比例缩略图；PDF显示首页，原文件入口保留整份PDF。普通报料、补库、现代实收卡及旧实收卡入口覆盖。原同版附页、产品二维码及客户随货版内部隐藏规则保留。
- 图纸未加载/损坏/失去权限时停止打印，可重新加载重试；保留原打印前新鲜数据和版本核对，不静默印出空图。
- 开发期间正式基线推进到v620，已整合并保留周需求、库存预览、简易报料条单、模具删除/搜索及发货原子提交兼容保护；简易条单继续保持十二列裁切样式，缩略图加入完整任务单。
