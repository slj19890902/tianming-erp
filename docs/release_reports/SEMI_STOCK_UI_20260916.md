- 黄色“半成品抵扣 · 可用张数”入口；可用候选张数与本次已安排需求片数分开，数量汇总按真实批次ID去重，原材料不冒充半成品数。
- 展开按正式货位ID一行显示数量、位置、尺寸、楞型、材质；绿色采用，红色不采用。位置仍可点开定位。

- 按货位可追加采用或取消本位，取消全部后本组件不抵扣；再次采用可恢复。明确排除的批次不被安全推荐立即重新选入。采用并非立即扣库，仍走订单保存与后端校验。
- 隐藏SI批次号、“本客户通用片料”、英文差异键与重复说明；跨客户保留短标识，点击采用承接既有人工确认，不取消后端权限和适用资格门禁。
- 加载/过期/失败不能采用；实际读取失败保留红色错误，不把故障伪装成正常库存。
