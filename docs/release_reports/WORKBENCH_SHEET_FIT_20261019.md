## 问题与修正

原查询使用长宽完全相等，漏掉近尺寸和能一开多的大片料。老板随后明确小尺寸需求应先使用小片料，保留难采购的大片料。现在默认只查接近尺寸：原方向每轴允许最多短10mm（含边界），正向最多超出10%（沿用已有近尺寸规则）。只有点击“扩大范围”才取消正向上限；空结果也不自动扩大。扩大后接近尺寸组始终先于大片料组，同组再按匹配度排序。选择整数网格，匹配度为两轴 min(实际尺寸,需求尺寸×份数)/max(实际尺寸,需求尺寸×份数) 之积；多开只允许整张每轴累计最多10mm短差，不按开数累加容差。分数保留两位，只有完全吻合才显示100%。同组同分优先更少开数，再按稳定批次ID排序；先筛选排序再分页。

需求1000×200时，默认显示1000×200、991×200、990×200、1100×200；2000×200、1000×400等仅在扩大范围后显示。各项评分：1000×200一开一100%；991×200一开一99.1%；990×200一开一99%；989×200排除；2000×200及1000×400一开二100%；2000×400一开四100%；1100×200一开一90.91%。1991×200按整张9mm短差可作一开二99.55%，1980×200不会将容差按两份扩大，只按一开一推荐。

页面增加“扩大范围 / 只看接近尺寸”切换、匹配度 / 开数和匹配度筛选，取消“按原长宽精确查找”文字；输入区明确为需要的片料尺寸。选中库存仍传递该批真实长宽、楞型和lot_id，返回列表保留原查询尺寸、匹配度、范围和页码；匹配度筛选保留扩大状态，修改需求长宽或楞型恢复默认范围。桌面及手机共用组件，两端入口引用新内容hash。客户权限、严格楞型筛选、无自动旋转、原数量/单位/位置及实际用途校验保持。仅只读几何推荐，不生成裁切执行事实，不影响报料抵扣或预占。
