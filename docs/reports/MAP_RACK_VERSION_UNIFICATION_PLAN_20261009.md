## 原因及需要修正的范围

1. 楼层地图更新会改变全层版本，区域策略却可能只更新本次选中区域；严格打印/归位门禁因此判其他区域为旧版本。
2. v576 的 unchanged-rack carry 仅迁移“恰好关联上一个版本、无草稿、完整区域及架不变”的 rack 策略，不能追补更早的旧关联，也未覆盖所有含架但仍使用历史 pallet_ground 策略的区域。
3. 一楼数据库 floor_code=F1，运行地图 floor_code=1F。warehouse_rack_map_application.py 按字符串相等查询会漏掉一楼；应复用按稳定楼层ID/楼层数字解析的统一方法，不为修此错误盲改正式楼层编码。
4. 模具位置、普通货位、地堆排位分别有业务身份，必须共同核对。不能删除严格版本、权限、容量、数量、事务和审计校验来让旧数据看起来可用。
