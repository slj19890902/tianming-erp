## 已修复的行为

1. `legacy_unset` 旧报料来源的新收料原来可以跳过冻结价；现与供应商采购、纸板补库共用 `freeze_receipt_settlement_price`。
2. 每条新收料都保存独立结算快照：稳定供应商、材质、尺寸、数量、单位、含税含运采购价、税率、来源和时间。现代采购复制已批准 `PurchaseReceiptFact` 的最终采购价；旧无用途合同来源只接受稳定供应商/材质对应的完整当前报价。内部用途成本不参与供应商应付价格。
3. 冻结后才处理库存、订单进度和成功审计；所有内容由调用方统一提交或回滚。同实收唯一快照、重试不重复入账。
4. `SessionLocal` 增加提交期校验，跟踪新建/恢复及数量、来源相关修改；不在无关提交时扫描或补写旧缺口。已保存实收不可换绑采购来源，冻结价不可更新/删除，普通 ORM SQL 和旧 `bulk_*` 写入旁路被拒绝。
5. SQLite 批量保存点使用真实外层事务，避免 RELEASE 在最终校验之前提交实收。已用故障注入复现原风险，并验证最终价格门禁/批量审计失败均回滚已释放保存点的实收、冻结价、进度和审计。
6. 旧 `manual_history` 纸板补库不能再直接生成库存，必须经有价的 `sr{id}` 实收入口。外购包材继续走其独立正式采购价格链。
7. 管理员缺价行提供“前往供应商材质报价”；新标签页修价，原收料页保留数量和幂等键，由用户重试。无报价写权限的文员提示联系管理员，不扩权。
