# P0-B 上传与图纸安全人工验收清单

## 验收边界

- 只在家庭电脑的隔离 UAT 数据库和服务中验收。
- 不连接、不迁移、不写入工厂正式数据库。
- P0-B 没有 Alembic migration。
- 明早工厂主机更新前，仍需先备份正式数据库并执行公开上传目录只读审计。

## 家庭 UAT

1. 使用管理员账号登录。
2. 打开“常用箱与材质”，选择一个有印刷的测试产品。
3. 上传一张真实 PNG/JPG 图纸，保存后确认：
   - 图纸历史新增一版；
   - “查看/下载”可以打开；
   - 浏览器地址以 `/api/master/products/drawings/` 开头，不出现 `/static/uploads/`。
4. 再上传一个真实 PDF 图纸，确认 PDF 可以打开。
5. 新建测试订单，在订单明细上传图纸后确认可以预览并保存订单。
6. 保存后重新打开订单，确认订单图纸仍可查看。
7. 尝试上传以下伪装文件，确认系统拒绝并显示“签名无法识别”或“类型不允许”：
   - 把 TXT 改名为 `.png`；
   - 把 TXT 改名为 `.pdf`；
   - `.html` 或 `.svg` 文件。
8. 退出登录后重新访问刚才的图纸 API 地址，确认返回未登录/无权限，不能直接打开。
9. 访问任意旧公开地址，例如 `/static/uploads/test.pdf`，确认返回 404。
10. 上传一份真实订单 PDF，确认 PDF 预览与人工确认流程正常。
11. 如现场仍使用天华预送货图片识别，上传一张真实 JPG/PNG，确认识别入口正常。

## 明早工厂主机发布前

1. 确认主机名为 `PC-20250926DZYH`，不是家庭电脑。
2. 对工厂正式数据库执行在线备份并校验 SHA-256、`integrity_check` 和外键。
3. 执行：

   ```powershell
   python scripts/audit/public_uploads_audit.py --uploads-dir "D:\纸箱厂erp软件搭建\static\uploads"
   ```

4. 如果报告存在异常文件，只保存清单并停止发布，不得自动删除。
5. 核验正式会话密钥至少 32 个字符；只有发现真实泄露证据时才另行授权轮换。
6. 安装并核验：
   - `python-multipart==0.0.27`
   - `pypdf==6.7.3`
   - `PyJWT==2.13.0`
7. 发布后重复家庭 UAT 的第 2～11 步，再决定是否完成 P0-B。
