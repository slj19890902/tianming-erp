# ERP 统一界面与完整生产安排

状态：实施中。老板 2026-09-12 授权按已审阅方案逐步实施并发布。

方案依据：C:/erp-ui-plans/20260912/ERP统一界面规划.md；NAS 同日《ERP统一界面规划-方案未实施》回执。

## 顺序与验收

1. 共用屏幕容量分页、加载/失败状态、可展开说明、仓库层级位置选择；历史翻页不能显示上一页数据。
2. 邮件单据队列与单份 PDF 核单分开；突出产品、数量、价格；库存覆盖和位置去重，分别展示成品、半成品、原料。
3. 已报料点击供应商进入关联采购单，保留单款撤销与下游门禁；统一来料页面。
4. 组合产品按有效 BOM 整组安排，子件独立实物账保留，共同计划位置，统一待生产入口。205 母件为虚拟件，不得伪造成品或猜测名称中的换算。
5. 财务、完工历史和其他列表套用统一规则；针对性测试、隔离网页核对、正式安全发布。

## 不变量

权限、客户范围、草稿、金额、数量、状态、幂等、事务、并发版本、审计、正式数据库隔离均保留。选择候选不冒充正式抵扣，计划位置不冒充实际移库。保留无关改动与现有业务数据。正式页面不自动点击验收。

## 工作方式

单代理在 C:/erp-worktrees/unified-erp-ui 的 codex/unified-erp-ui 候选分支实施。主仓库未跟踪 TianmingERP/ 属于其他工作，禁止纳入或删除。每阶段完成最小闭环验证后继续，全部完成再统一发布。发布前实时核对基线、唯一迁移头、验证备份与隔离演练；发布后只读检查与管理员验收。

## 205 口径补充

老板确认：每套网格长片 3 只＋短片 4 只，一只纸箱配 5 套网格，即长片 15 只＋短片 20 只。生产填写 BOM 网格套数，整箱包装数量不再乘入一次。只读核实该虚拟网格与整箱父件是不同产品，整组生产按网格有效 BOM 执行，未改正式主档或库存。
