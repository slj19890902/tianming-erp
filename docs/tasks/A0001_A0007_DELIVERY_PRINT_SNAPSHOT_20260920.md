# A-0001/A-0007 历史送货打印字段契约

日期：2026-09-20

状态：已完成并正式发布，版本 `v0.22.462`，数据库 revision `dc0920`。

## 目标

新建送货单时冻结客户抬头、联系人、电话、地址及本公司打印抬头，确保以后修改客户或公司主档不会改变已建立送货单的打印内容。

## 边界

- 新送货单使用显式版本化快照；快照中的空值也保持为空，不读取未来主档补值。
- 既有送货单没有历史证据，不猜测、不回填，继续使用当前主档兼容显示并明确标记为旧单回退口径。
- 不修改订单、数量、库存、发货、回单、财务或既有打印事实。
- 迁移只增加可空字段；有新快照事实后禁止直接降级删列。

## 验收

- 新送货单建立后修改客户和公司主档，再次读取打印数据仍返回建立时内容。
- 新建时为空的字段不会被后续主档补值覆盖。
- 旧送货单继续可打印并返回 `legacy_current_fallback` 口径。
- 隔离迁移升降升、非空降级拒绝和定向测试通过。

## 完成结果

- 新建送货单在同一创建事务内冻结客户和本公司打印抬头，包含创建时的空值。
- 旧送货单不猜测历史主档，打印接口返回 `legacy_current_fallback`；新单返回 `frozen_v1`。
- 正式库原有 135 张送货单没有回填快照事实；迁移后快照版本非空记录仍为 0。
- 正式发布包 `044d81ac965349a3e147a381be201eb0232ac08b972e57947c78e5f2aea1d088` 已上线，完整性正常、外键异常为 0。
