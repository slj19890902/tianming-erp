# A-0002-R4 订单余料转生产适用边界

日期：2026-09-20

## 目标

验证订单来源余料转待生产时，历史冻结换算事实与当前可用范围的边界：冻结的每张产出数不能被当前主档覆盖，但客户、产品有效性、虚拟组合身份及批次当前允许产品范围仍必须实时校验。

## 范围

- 为订单来源余料补充边界回归测试。
- 仅在测试证明现有实现违反冻结事实或当前适用范围时修改服务。
- 不改写历史订单、库存数量、预占、成本或正式业务数据。

## 验收

- 当前产品主档规格或换算改变后，订单来源余料仍使用冻结换算事实。
- 产品停用、删除、跨客户、虚拟组合或不在批次当前允许范围内时明确阻止。
- 失败不得产生预占、库存流水或状态变化。
- 定向测试与差异检查通过，并写 NAS 独立任务回执。
