# A-0004-R2 订单执行数量与状态同屏

日期：2026-09-20

## 目标

在订单明细追溯页增加紧凑的执行总览，让办公室人员不必在订单、来料、生产、库存和送货页面之间来回核算即可区分订单量、累计实收、当前成品、半成品余料、已送、未交和当前可送。

## 业务边界

- 数量只由后端根据真实订单明细、有效收料、精确关联库存和已送字段投影；前端不推算正式库存。
- 成品与半成品分单位展示，不把纸板张数和成品只数相加。
- 当前可送受未交数量封顶；没有成品库存时明确显示“暂无可送”。
- 无权限阶段不泄露数量，显示受限状态。
- 每个可追溯指标绑定真实来源记录，可打开现有精确阶段详情。
- 不修改订单、库存、预占、收料、生产或送货事实。

## 验收

- 追溯弹窗同屏显示订单、实收、成品可用/预占、已送/未交、当前可送、余料张数。
- 数量旁显示单位和来源口径，完成、待处理、暂无可送、权限受限有明确颜色状态。
- 点击来源按钮读取现有精确来源 API，不做模糊定位。
- 通过服务、接口和静态前端定向测试，按正式发布门禁交付。
