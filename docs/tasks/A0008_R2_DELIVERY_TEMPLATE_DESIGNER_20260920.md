# A-0008-R2 管理员送货模板最小设计器

日期：2026-09-20

状态：`v0.22.464` 已正式发布，待管理员在实际前端完成人工验收

## 目标

在现有送货打印 DTO 和纸张校准之上，提供受限的送货单版式编辑、匿名预览、草稿、发布、客户绑定和版本回滚。新建送货单冻结采用的模板版本，历史重打不随以后模板变化。

## 最小闭环

- 白名单版式元素：公司抬头、单据标题、客户资料区、明细表、合计备注、签字页脚。
- 管理员可调整元素毫米偏移、字体/行高和八个明细列宽；价格字段始终不进入模板字段目录。
- 保存草稿不影响打印；发布形成不可变版本。模板可作为默认模板或绑定单个客户，客户模板优先。
- 回滚通过发布一个指向既有版本的新版本完成，不改写旧版本。
- 新建送货单同时冻结模板版本、内容和哈希；旧单明确使用旧单默认回退，不冒充历史模板。
- 模板只控制显示，不执行表达式、脚本、SQL，不修改数量、金额、库存或业务状态。

## 验收

- 普通用户只能读取已冻结的打印结果，不能保存、发布或回滚模板。
- 两个管理员并发基于同一发布版本修改时，过期请求被拒绝；同一操作键重放不重复建版本。
- 匿名预览覆盖一行、跨页、长名称、空值、零值、重复表头、页码、合计和签字区。
- 客户绑定优先于默认模板；发布后旧送货单重打保持原模板，新送货单采用新版。
- 隔离迁移升降升、非空降级拒绝、前后端定向测试、正式备份与发布门禁通过。
