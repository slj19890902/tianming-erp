# 区域整架标签批量打印与走纸排查

用户要求诊断整架标签偶发缺二维码/重叠，并在选中区域后直接批量打印整架编号+二维码。用户确认机身FEED只走半张：硬件走纸问题不能宣称由ERP修复。只读检查本机两个40x80队列尺寸正确，旧同USB002队列纸高30mm；保留所有打印机配置，不擅自重置。

范围：新增区域批量入口、每架一个正式授权货位作为身份凭据，保持楼层/区域范围；缺少正式货位明确阻止而不静默漏架。打印页URL直接rack模式；整架二维码与编号仍合成一个320x640位图，全部解码和排版后才能打印。保持手机URL、纸型、权限、数量、历史与无关改动。无迁移。

验证：区域排序/隔离/漏架保护，直接rack模式与QR失败拒绝，40x80打印媒体、旧入口及产品标签回归。实机FEED及实体打印待人工。
