# BOMUI001 常用箱组合关系易懂展示

## 范围

- 基线：`origin/factory-current-baseline` / `005a5a9fb62dac6e145433f872dbdf0678eedf2c`（v390）
- 分支：`codex/bomui001-20260913`
- 闭环：在常用箱的“组合 BOM”配置区展示易懂的动态父件/子件组合关系，并将编码、名称、规格分开显示。
- 组合摘要按当前父件单位、子件单位、实际 `quantity_per_set` 生成，例如 `1只 = 2只 A-01｜长边 + 3片 B-02｜短边`；不固定“套”，不虚构比例。

## 不变量与边界

- 库存来源、父件单位、计价方式和交付方式仍是独立字段与原有绑定；仅改善标签和说明文案。
- 不改真实产品名、BOM 数量、保存字段、API、版本、权限、客户范围、状态、审计或数据库事实。
- 不改后端、迁移、正式根目录、服务或网络；不执行正式页面自动点击、IAB 验收或发布。
- 未选择子件或单位/数量缺失时显示待完善提示，不用默认比例冒充真实关系。
