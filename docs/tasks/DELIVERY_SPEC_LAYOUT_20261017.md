# 通用送货单规格与列宽返修

用户要求：JSD等通用送货单规格只显示常用箱产品规格，缺失留空；不再显示模具位置、模数或待完善。当前通用版存货编码加宽约两个数字字符，单位二字横向排列。

单代理，复用当前v669代码工作区，只改当前送货描述投影与通用打印排版。根因已复现于delivery_specification：模切分支直接返回模具货架位置和模数，覆盖成品尺寸。不得改生产、仓库、模具和标签使用的product_stock_specification；不得写历史冻结快照、价格、数量、预占或正式产品资料。
