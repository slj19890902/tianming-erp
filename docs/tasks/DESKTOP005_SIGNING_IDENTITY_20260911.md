# DESKTOP-005 本机固定发布身份
为已授权完整安装更新交付准备固定发布身份，独立初始化命令与构建分离。允许 signing.py、build.py 及专属测试。私钥 DPAPI 加密，目录 ACL 当前账户和 SYSTEM，输出仅公钥指纹；存在的身份不得自动轮换。构建加载后复核公私钥一致。先临时目录测试，正式初始化独立执行，不替换旧预览身份，不发布测试私钥。跨电脑私钥备份和 Windows Authenticode 仍需独立落实；不可称为均已完成。

补齐加密导出/导入：独立 getpass 口令输入，两次确认导出，AES256-GCM与固定600000轮PBKDF2-SHA256，指纹绑定为AAD。备份回读解密核对；恢复只写空目录并重新DPAPI保护，既有身份/备份不覆盖，明文私钥仅内存存在。8项签名/构建测试通过，含错口令/篡改/目标已存在阻断。仅临时测试身份完成往返，真实发布身份仍需管理员在本机设置恢复口令后导出；未冒用测试口令，也未宣称完成真实跨电脑验收。
