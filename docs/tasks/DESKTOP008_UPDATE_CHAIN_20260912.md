# DESKTOP008 漏装中间版本的安全连续更新

目标：修复助手只取latest.json而精确跨版契约只允许上一包，导致漏装中间版本的电脑无法更新。先按签名契约回溯NAS哈希命名包，完整验签/内容核对、验证链和缓存全部所需程序后，逐步调用原更新流程。每步仍先NAS完整备份、隔离迁移、事实/附件/schema核对再更新启动；失败停止后续步骤，已完成步骤不回写旧数据库。
范围：desktop_assistant/manager.py、gui.py和专属测试；安装器/发布元数据与回执。当前正式基线442d8a42，v362/st32。单代理独立worktree。无新迁移，无正式业务事实修改，不接管正式库。权限、精确旧包身份、单操作锁、回退兼容和隔离门禁保持。备用电脑/实体打印须用户现场验收。
验收：跨两次revision且有同revision桥接包、缺包/错误哈希/无契约在停服前拒绝、中途失败停止并保留事实、重复更新无操作；原恢复和跨版回归。真实签名链读取和最新包runtime隔离证明，不冒充备用电脑验收。

回归发现现场无关NAS安装器进程的路径resolve报WinError1005，阻止恢复前进程检查。只对与目标python.exe同名的可执行文件继续解析路径；无关安装器不触碰NAS路径，目标进程检查和无法判定目标Python时的拒绝保持。

旧助手EXE不能靠业务程序包自动改变自身。安装器新增识别已有助手目录后仅原子替换助手EXE的入口，明确提示关闭旧助手，保持shared和配置原样，并更新离线程序包以供尚未接入的旧安装首次导入使用；空目录仍按原安装流程。由管理员运行新安装器操作，不自动接管正式系统。
