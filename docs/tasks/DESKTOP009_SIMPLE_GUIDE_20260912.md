# DESKTOP009 恢复助手分电脑用途引导

老板：按钮过多、含义不清，需要工厂电脑与工厂损坏时备用新电脑的独立操作提示。
目标：两个用途页签，工厂日常按钮+首次备份说明；备用机四步恢复/地址/打开核对/备份设置。技术修复、旧系统首次接入与AI密钥收进可收回的其他设置；按钮按实际安装/中断/回退状态启用。成功提示用操作员语言，安装器完工提示与新入口一致。
边界：仅GUI、安装器提示、说明、专属测试及版本发布；不改恢复/备份/迁移算法、密钥保护、空安装隔离、单操作锁、签名或附件校验。不实际恢复正式库，不接管或关闭原ERP；管理员旧备用机恢复已反馈通过，不重复索证，本版界面待人工验收。
单代理独立worktree codex/assistant-simple-ui-20260912。正式起点83fe71a6/v370/mq0912，无新增迁移。定向验证GUI页签/收起/空安装/忙时/恢复结果与原更新恢复，构建完整EXE安装器并验签、自检后按既有发布授权交付，NAS独立回执。

开发验证：25项GUI/恢复/安装器替换/构建测试通过，含两个用途入口、更多收起、空安装与已有数据按钮状态、忙时重复点击、取消无操作、恢复后下一步提示；隔离Tk窗口不触碰正式系统。唯一head保持mq0912。
