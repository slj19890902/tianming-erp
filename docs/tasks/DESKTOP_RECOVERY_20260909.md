# 天明ERP助手：方案二开发候选

用户2026-09-09选择标准安装包、独立更新器、NAS完整恢复体系。独立分支codex/erp-desktop-recovery-20260909，起始正式51ad75dc/v0.22.290。现有工厂部署不被本次开发接管，不自动注册本机备份任务。本候选不是正式部署完成，也未证明换到另一台物理电脑可直接投产。

## 已实现

- 独立Windows助手、桌面安装入口，程序与shared业务目录分离；安装目标必须为空。助手不依赖原ERP进程或浏览器。
- 离线运行环境包含Python3.12和当前ERP依赖、OCR组件；发布包不含数据库、上传附件、.env和发布私钥。
- 发布包使用Ed25519签名并在助手中固定公钥；NAS latest索引只能选择包，不能绕过发布签名。Git提交需经过开发端构建及发布程序后才进入NAS，原始Git推送不直接在工厂运行。
- 更新/回退先正常停止助手拥有的进程，再创建完整加密备份、解密复验及NAS复制校验。失败不标记新备份成功；不停止端口相同的外部旧ERP，不强杀未知进程。
- 同数据库revision的版本更新可切换；启动失败切回旧程序；回退只改变程序，保留更新后新增订单。每次操作有独立备份和状态记录，文件锁拒绝并发维护。
- 完整备份包含托管数据、附件、配置和对应签名程序包；PBKDF2+AES256-GCM流式加密，恢复口令可跨机器使用。计划任务所用口令由当前Windows用户DPAPI保存，不放进NAS知识库或Git。安装目录ACL限当前用户及SYSTEM。
- 恢复只允许全新安装；检查解密认证、归档路径、重复路径、文件hash、发布签名、数据库完整性/FK/表计数/revision。历史PDF绝对路径在恢复副本中重绑定并验证附件hash，缺附件停止；不会改原库。
- 首次接入旧ERP为停服后的只读复制；非标准数据库路径/外部自定义路径/目录链接必须先核对，不猜测。原目录保留。
- UI提供设置本机LAN地址、打开ERP、检查并更新、回退、立即备份、NAS恢复、首次接入、23点备份设置。
- 计划任务每日北京时间23点、登录补做、失败每小时重试；已完成当晚备份则跳过重复备份。任务使用当前登录用户以访问NAS，电脑须开机且用户保持登录（锁屏可）；注销后备份不执行。任务注册仅由安装后设置按钮触发。无人登录备份需要后续工厂配置专用服务账号，不能冒充已支持。
