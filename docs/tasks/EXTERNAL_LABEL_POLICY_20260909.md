# 外购常用箱标签策略

用户确认：箱型“其他”的外购材料允许勾选打印标签，编辑的是每张标签/每捆数量；保存后后续新标签按新数量计算。

基线：25e63a0b；独立分支 codex/external-label-policy-20260909。
根因：前端隐藏外购标签设置，构建保存请求及后端清除纸板生产字段时均强制清空标签策略。
范围：去除三处阻断，沿用现有整数校验、主档版本保存、回读、当前标签策略读取及历史打印冻结。虚拟组合父件按子件交付的禁用规则保留。
不变量：不改订单/采购比例、实收/库存/送货数量、客户范围、权限、版本冲突、打印幂等和已打印历史；不代用户批量启用或填数量。
验证：外购新增启用、50改20保存并回读、旧版本409、旧客户端未提交标签字段时保留、非法数量422、显式关闭走原确认；送货新标签张数按当前每张数量重算且总交付量不变。原主档保存和打印作业冻结/幂等回归。无新migration。
