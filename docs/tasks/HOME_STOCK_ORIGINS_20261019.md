# 首页库存来源与生产入库分流

授权：老板2026-10-19明确要求执行本聊天展示方案并发布。

范围：首页产品搜索优先显示自有成品数量、可用和占用；授权共用可用单列。
数字打开独立来源弹窗，盘点／补库生产／订单生产使用蓝／紫／绿底色，其他来源灰色。
批次按真实来源追溯订单、报料、实收、入库、库存占用／释放、移位和出库；未记录不推填。
生产工作台已入库只显示订单生产和补库生产；显示来源、入库时间和详情。
当前生产资料保留工艺、模具和图纸，并补充印版版本与位置。

不变量：只读投影，不修改正式业务数据、数量、成本、预占、冻结历史和客户权限。
移库保留原入库来源；盘点校正不重写生产来源；同一批次不在自有库存重复计数。
关闭弹窗不刷新原列表，保留筛选、分页、滚动位置和焦点。接口失败不得显示为零库存。
