# 库存录入资料及成本闭环（2026-09-22）

依据本次老板明确指令实施；单代理，独立 worktree，正式业务事实不回填。

## 可观察结果与方案

1. 新实物入库统一核对单位、可用尺寸、供应商材质报价；缺失不再保存为零成本。已知纸箱按常用箱报料尺寸和有效平方价计算，A1 缺报料尺寸可复用现有公式；原材料和半成品按片料长宽。多片、开料率、组合件及外购计价沿用真实业务契约。
2. 手机和电脑复用入仓前常用箱编辑，补单位、箱型、材质、尺寸后回到原库位数量；提供报价维护及重新检查入口。草稿允许待完善，但不能作为无依据正式库存。
3. 客户未知的成品按“客户待认领”实物入库，不虚构客户、常用箱或订单。A1 按实测长宽高、拼片方式及搭舌计算；其他箱型填写实测展开尺寸。人工选择估算材质，冻结公式、尺寸来源、报价版本、单位、操作人，明确参考估算。身份未核实不能直接用于客户订单发货。
4. 来源采购或生产的既有实际成本及转换继承继续保留；移动旧库存不重新计价。新入库不得用售价自动掩盖材料成本缺口。

## 不变量及边界

库存唯一数量账、空间投影、权限/客户范围、状态/版本、幂等、事务、审计、历史冻结不削弱。仅管理员原有纠正权限可新增通用实物及维护成本；不向无成本权限员工泄露报价。人工估算不是历史采购事实或生产确认。已有库存不改价、不改变归属。
