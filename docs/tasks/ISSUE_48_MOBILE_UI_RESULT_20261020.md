## 实现与设计对照

| 页面 | 实现 |
| --- | --- |
| 首页 | 绿色四个业务入口、真实待收料/未送齐数量、经营摘要和底部导航；入口按后端权限显示。 |
| 现场查询 | 产品/纸板/货位切换，短码、短货位、扫码或手输查询、分页；扫码沿用既有标签身份规则，拒绝外部站点地址。 |
| 产品详情 | 大号可用库存、各货位数量和来源统计，报料尺寸、压线、工艺、模具位置、真实图纸预览、原盘点入口。 |
| 认纸板 | 按实际报料尺寸查询，默认公差±5mm可调整、结果分页；不嵌入设计稿样例产品。 |
| 仓库地图 | 实际楼层/区域几何、货位、库存信息、放大缩小、货位选择与盘点入口。地图形状取决于现有API，未复制设计稿静态示例图。 |
| 收料 | 待收料/已收料、尺寸楞型数量卡片、展开加载供应商/产品/工艺/图纸，原收料与撤回接口；失败保留卡片、防止重复提交，撤回仍需原因。 |

所有页面采用绿色 `#2e7d4f`、蓝色数字/链接、正文至少15px、主要数字至少24px；主要按钮/导航至少48px。移动页面内部滚动，底栏不遮挡产品操作按钮。短码只改变显示，查询/写操作仍传原始业务ID。保留原扫码、盘点、预送货及生产只读入口。

## 权限与现有数据边界

- 用户明确同意：保留既有后台授权，财务不能读取的销售额、材料成本、材料毛利和毛利率显示“—”；不请求未授权成本接口。
- 普通员工不请求经营金额，不展示无权限业务动作；会话失效清除移动权限缓存并回到登录。
- 隐藏或缺失库存显示“—”，不伪造为0。当前地图API未提供最近实际盘点数量，相应字段显示“—”，不以账面数量冒充盘点结果。
- 接入现有API契约，未增加或修改后端接口。没有读取生产业务数据，也没有写数据库或部署生产。
