## 打印配置与实机验收

当前佳博队列默认介质为 `w76h130mm`，与三种网页纸型均不一致。网页 `window.print()` 无法设定驱动介质或强制系统对话框；候选仅保证 ERP 预览、冻结纸型和 CSS 页面一致。管理员需在客户端浏览器打印界面为本次作业选择与页面相同的纸型，缩放 100%、边距无、关闭适合页面/自动旋转/页眉页脚；40×80 在驱动中建 `Custom.40x80mm`（若驱动和纸张支持），80×40 使用 `w80h40mm`，40×30 使用 `w40h30mm`。不要全局修改默认纸型。方向最终以真实出纸为准。

人工验收三步：
1. 在正式页面只读刷新 598 和一条 JSD 明细，核对来源、客户、编码、每张真实数量与尾数；再分别选三种纸型预览，确认编码完整且没有产品名称。
2. 管理员在客户端佳博打印机上用“ERP 按钮→浏览器打印”和“使用系统对话框”各打印一张同一冻结作业，记录介质、方向、缩放、边距、进纸方向、是否裁字；只有真实出纸后登记“确认已实际打印”。
3. 检查同键重试、旧作业补打仍保持原布局；若任一尺寸方向不一致，停止该纸型上线并记录作业参数。
