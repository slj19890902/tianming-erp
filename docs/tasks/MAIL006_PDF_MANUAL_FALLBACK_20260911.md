# MAIL006 邮箱 PDF 人工录单兜底

## 目标

让已成功收取、但客户格式尚未配置而无法识别订单号的 PDF 继续进入受控订单草稿，避免文件可读却无法录单。

## 范围

- 识别失败或无明细的 PDF 显示“按原 PDF 人工录入”。
- 操作员选择正式客户，填写客户单号及逐行订单事实。
- 后端使用原 PDF 签名重新核对文件身份，并仅按所选客户的正式常用箱匹配产品。
- 保存继续执行客户范围、整数数量、单价、生产提醒、库存、重复订单、幂等、事务和审计门禁。

## 不做

- 不自动猜测或补写客户单号、数量、价格等订单事实。
- 不自动创建新常用箱。
- 不修改已同步邮件、已有订单、库存、价格或生产数据。
- 不新增数据库迁移。

## 验收

1. 失败 PDF 可进入人工录入，输入编码或名称、数量后重新匹配常用箱。
2. 文件名或哈希被替换时拒绝，空客户单号、空产品、小数或非正数量拒绝。
3. 未匹配常用箱、缺单价、未确认生产提醒或库存决策时不能保存。
4. 完整人工草稿可保存，安全覆盖进入审计；普通 PDF 与普通订单流程不受影响。
