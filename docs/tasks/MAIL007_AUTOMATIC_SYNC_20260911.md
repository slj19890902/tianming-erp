自动任务仅使用 IMAP `EXAMINE` / `BODY.PEEK` 分批读取，每批最多20封；剩余邮件5秒后继续，平时按管理员设置的1至60分钟间隔检查。邮件不会被标已读、移动、删除或发送，附件仍按大小、类型、哈希和稳定 UID 门禁保存。任何邮件都不会自动创建订单。

邮箱设置新增启用/暂停、间隔和最近运行状态。新保存授权码默认启用5分钟自动读取；已有正式授权码在迁移后保持暂停，正式启用必须作为本任务的独立审计配置动作执行。自动运行使用“系统自动收件”身份记录审计，不冒充管理员。

迁移 `sr30v8x9z92` 只增加自动读取配置与运行状态字段，不修改既有邮件、附件、草稿、订单或其他业务事实。有自动配置或运行事实后禁止破坏性降级，回退使用发布前完整备份。

正式页面不自动点击。发布后管理员最短验收：查看自动状态；发一封PDF并等待自动出现；打开附件确认仍需人工保存订单。
