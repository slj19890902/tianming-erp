# 手工选择库存片料并决定抵扣数量

用户已要求实施：普通订单、组件待报料及采购草稿增加“使用库存片料”，用户逐批决定本次使用张数。

## 最小闭环

只读查看批次、位置、可用量、材质和加工差异 → 用户填张数 → 点击确认采用 → 原库存服务预占 → 更新剩余物理片和采购张数。输入默认留空，不自动用完库存；取消查看不建需求或预占。支持普通双拼、BOM、理论片料模切产出、合法原板裁切；供应商开料倍率不重复乘到理论库存片料产出。

对无专用绑定的原板，人工采用需要确认页面全部差异；只针对本次预占生效，保留原材质、尺寸、成本和客户范围。异客户、异楞、面纸/层数/用途或加工状态不符仍不可采用。跨客户权限不扩大。

超可用/超需求、旧版本、越权、已完工/结档或已有正式报料拒绝；相同凭证重试不重复，换载荷拒绝；审计与预占原子。网络结果不明确时保留原批次、数量、确认依据和凭证，先核对原操作，父页面暂不允许保存采购。普通订单与BOM共用预占执行，分别冻结各自需求。

抵扣后的BOM草稿刷新服务端需求依据，保留该行备注和另外填的补库采购量；普通草稿复用现有重建流程。发现并修复相邻错误：普通父件需求读取半成品预占时未排除BOM子件，导致子件抵扣混入父件外包装报料。现在只读各自范围。
