# MOBILEQR001 二维码标签手机化与旧码兼容

范围：先修复整架二维码错误进入电脑仓库地图，再统一库位、产品、库存批次、模具、生产任务、来料与送货拣货二维码的手机入口；兼容仍能访问系统的旧打印码，并让内置扫码器识别受信任的旧 ERP 地址。

成功：新二维码只使用配置的手机访问源地址；对象语义保持一致；扫码未登录后返回原对象；桌面仓库地图和嵌入式生产流程保持；旧码兼容矩阵、无法兼容原因和补印清单明确；40x80 与现有标签打印效果不退化。

不变量：扫码 GET 只读，二维码不授予权限；客户范围、权限、数量、事务、版本、审计、正式数据、历史打印任务与历史标签记录保持；不修改或补造正式业务事实；不运行正式页面自动点击验收。

验证：服务级与路由级定向测试、前端扫码路由测试、真实二维码解码、隔离 Chrome 打印版式、完整差异检查；发布前核对正式基线、备份、迁移头唯一性、回滚包与健康检查，发布后只做只读接口和静态资源核对并交管理员人工验收。
