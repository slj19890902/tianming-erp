# 模具标签图号与双出纸方向（2026-10-16）

老板要求新建的 80×40 mm 模具标签改为：第一行左侧显示实际存货编码，右侧显示较小“图号”和与左侧编码同级的实际产品图号；第二行保留模具位置和几模，位置前缀简写为“位置”；17 mm 模具侧面区域上下各有一条虚线，客户简称右侧显示加粗存货编码，原位置二维码保持 15×15 mm；底部片料尺寸位置不变。纸张支持现有 40×80 mm 竖向出纸和未来 80×40 mm 横向出纸，两种方向均为横向阅读的同一标签内容。

只改新打印任务的版式和打印页纸张方向，历史冻结版式及打印任务继续按原目录解码。图号从产品 `customer_drawing_number` 读取；缺失时显示“待完善”，不拿产品名称冒充图号。无数据库迁移，不改订单、库存、模具绑定、二维码业务身份或正式业务数据。打印尺寸、版式坐标、图号来源、权限及冻结重打须定向验证；正式发布后交管理员实机贴标和扫码验收。
