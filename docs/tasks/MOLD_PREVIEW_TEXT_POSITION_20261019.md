# 模具标签预览直接编辑全部文字与统一简略位置

用户要求：聚晟达侧面12mm加粗存货编码过长时，预览内可直接改；每张标签所有可见文字均可编辑，保存后打印且作为这款标签以后打印默认内容。天华21301834等同样适用，不再返回模具编辑；R01～R04所有模具位置统一显示R01-2-1（架-层-格）。

范围：当前40×80模具标签单张/批量逐行文字；标签显示内容独立保存，不改产品编码/图号/尺寸、模具位置身份/二维码、数量成本预占。支持明确留空和恢复默认，区分共享模具的全模具显示默认与选定产品显示默认。保存保留权限、客户范围、版本、幂等、审计及事务；历史冻结打印作业不重写，编辑后生成新冻结作业。保持既定纸型、侧面17mm高度、15mm二维码、12mm侧码字号及溢出检查，不以裁切或任意缩字号绕过超长。

位置：从现有稳定cell/rack/level/grid关系派生紧凑显示，不新建区域、格位或改rack_location；旧位置码能可靠解析时同样显示，不猜补缺失层格。订单/仓库/标签/生产/手机等共用显示口径，保留停用资格和归位校验。

现有缺陷：mold-label-preview.js仅允许单产品且title_kind=name的标题输入；保存接口只存product_titles，draw客户和侧面编码不可改。当前模具位置API和部分前端仍用alias/长prompt，显示不统一。
