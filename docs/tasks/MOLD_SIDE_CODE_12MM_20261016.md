# 模具标签侧面编码 12 mm

目标：在既有 80×40 内容区的 17 mm 侧面区域中，二维码旁的实际存货编码用 12 mm 加粗字号等比例显示，完整容纳 `Z.001.000001`。二维码、两条虚线、顶部字段、片料尺寸与两种出纸方向保持原位。客户简称移至编码上方以腾出横向空间。

实现：新目录 `mold-side-code-12mm-v1`，旧目录及已冻结打印任务不改。侧面编码 x=1.2、y=20.8、w=61.2、h=12 mm；使用 Arial Narrow Bold 字形，字距 -0.05 mm，仅用于消除字间空白，不做水平拉伸或压缩。二维码仍为 15×15 mm，x=63.6、y=17 mm。侧面上下虚线仍为 y=16、32.8 mm。

验证：Chrome 实测 `Z.001.000001` 的内容宽度约 60.1 mm，小于可用约 61 mm；黑色字形在 12 mm 高元素中完整显示。模具标签针对性后端及前端测试通过。正式发布须经现有 Mac 发布器验签、隔离演练、冷备、切换和只读复核；实机纸张和扫码仍需现场核对。
