# MULTI-MOLD-COMPONENTS-20261010

## 范围与成功条件

老板提出同尺寸纸板分别经 A、B 两块模具模切后粘合。沿用真实子件 BOM，每个子件独立模具、工艺、每套用量及开料出数；常用箱可直接维护并看清所用模具。标签提供员工识别用途（A模、B模等），不改客户产品名称或模具稳定身份。

本轮最小闭环：补齐 BOM 子件配置与回读、更换子件模具后父件草稿同步、每个子件生产资料显示和现有模具标签用途编辑说明，定向隔离验证。

定向验证发现首次保存两处关联缺口：前端新父件未携带 BOM，后端新建组装父件可能在配方保存前被按无需结合子件归为“片”。本轮一并补齐原子首次保存，新组装父件按老板已确认规则为“套”；已有父件存储单位和历史订单不回写。
