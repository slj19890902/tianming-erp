# 研光/光洋清单订单导入与提前备货

用户已确认方案与 L=单价、M=金额，授权开发。支持无表头 A 产品/B 图号/C 指定位置/D 编码/E 需求/I 类别/J 原表库存/K 原表余量/L 单价/M 金额。需求完整导入；J/K 不写库存；不猜客户单号或交期，客户/日期在界面选择。相同编码多行不合并，保存原表位置、行序和参考量。

导入保存后及订单详情提供提前备货单，不依赖送货单；列出缺货/未生产行、指定位置、当前可拿、待补和手写实拿。来源字段纳入已有签名与来源行 JSON，无迁移。客户范围、产品身份、数量单位、预占、幂等、事务、审计沿用原机制；只读打印不扣库。无法唯一匹配的位置保留原文、提示核对，不推测复合位置。
