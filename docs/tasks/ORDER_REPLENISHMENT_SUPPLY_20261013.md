DTO 合同：`replenishment_supply.covered_finished_quantity` 是本单因补库新增的产品/父套覆盖，`remaining_purchase_finished_quantity` 是仍需采购的产品/父套缺口，`total_coverable_finished_quantity` 是实物/本单已采购/补库共同可覆盖上限；三者都不是可送数量。`sources` 逐来源给阶段、采购折算片数及真实来源库存产品单位。BOM 父套按冻结组件配比的最小完整配套量计算，不累加组件片数。
