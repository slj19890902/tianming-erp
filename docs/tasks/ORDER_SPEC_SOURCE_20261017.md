# 订单规格混入模具资料原因排查与修复

用户要求：研光、海外部分订单规格显示模具及模数，须排查为什么不统一；模具位置只显示位置，不加其他信息。

根因：resolved_product_specification在冻结规格缺失时回退product_stock_specification，后者在成品尺寸缺失且有明确模具/模数时生成工程身份文本。订单新建/编辑、列表响应同时复用此函数，导致既有动态回退又有已写入历史快照的自动文本。2026-10-17修改849508361/ed86ebfcf引入该回退；v670仅修复送货规格，订单入口未修。已有v669-r2只读发布副本（不是最新正式库）中，研光TM20260928004的80011906等快照已含该文本，80019977则有345×182×246成品尺寸，展示差异可精确复现。该副本未含后来新增海外订单，不冒充正式最新影响统计。

范围：订单专用规格解析；保留真实冻结规格，已知自动生成模具身份文本只在订单展示投影中过滤，缺失时只取常用箱成品规格，不从名称、模具或报料推算；新建/编辑不再写入模具身份文本。重复订单判定采用同一规格归一规则，保留去重保护。模具位置使用已有位置短标签或原始位置码，不拼模具编号/模数/操作提示。原始数据库快照、仓库工程身份、生产、库存、价格、成本、预占、客户范围及审计门禁不改。

单代理、当前v670工作区定点修复。先复现失败，再定向检查；不扫描全盘，不全量测试，不读取凭据。无正式历史修复和停服发布当次授权，先完成候选和结果，不能称已上线。
