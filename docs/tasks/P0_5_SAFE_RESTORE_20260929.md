## 最终实现

1. `POST /api/system/backups/restore` 保留管理员权限检查，但服务端固定拒绝在线恢复并返回 409，明确要求使用“天明ERP助手”的 `.tmbackup` 完整恢复；直接请求也不能进入旧单库替换函数。
2. 新增只读 `GET /api/system/backups/managed-status`，按 `system.backup` 权限读取助手状态、发布版本和备份回执，只返回非秘密字段。回执、文件、大小或路径不一致时不显示为已验证。
3. 网页将旧 `.sqlite3` 清单明确标为“数据库快照”，与助手“完整备份与恢复”分开；页面只展示完整备份创建时的验证状态和助手操作指引，不在网页执行恢复。
4. 继续复用现有助手的完整包校验、解密、文件哈希、发布签名/版本配套、迁移版本、必要业务表、附件、空安装目标及失败不激活机制，没有另建备份或恢复框架。
