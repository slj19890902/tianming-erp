# R08 统一原片采购

老板授权连续开发、验证和发布。本闭环仅 R08，不引入第二本库存账。正式基线 R07 v457 / fd8e8da8，DB up0919；实际发布时重新核对。

待报料显式选择来源，后台重新读取全部冻结物理需求，预览实际原片尺寸、方向、出数和每条分配。不同材质、楞型或客户不得隐式混用。原最终规格不改写。采购总数 = 分配原片数 + 备用原片数；片数按每来源明确出数折算，不能和张数相加。

复用现有补料采购来源和真实原片收料库存，将原订单需求及分配新增为不可改写来源关联。收料后才形成原片和预占，实际厂内加工确认后才转成品；备用保留原客户及产品范围。冻结需求、订单改量/删除、重复报料、撤销、并发、成本和事务均须定向保护。新增关联表无历史回填，完整备份、隔离升降升及历史摘要、唯一head通过后再发布。

验收：20盖+20底采购45张，先45原片、分配40待加工、备用5，确认加工后20套与5原片；供应商打印实际无压线规格，车间保留盖底最终规格。方向/尺寸/出数不合法拒绝；预览不写库存，同键重试不重复，旧普通采购不变。R09随后继续。
