# R09 天华持续待补送

老板已授权从R02持续开发验证并发布至全部完成。本闭环R09，基于正式v459/rp0919，独立工作区codex/package-d-r09-20260919。发布时重新核验实际基线。

预送货明确“等待下次送货”持久保存客户、真实产品/订单、通知来源、客户订单号、交期、需求、原因、创建时间和实际发货关联。与原订单欠送关联，不能另加到欠送总数或把新同款订单当已补送。重复通知对同订单只合并追踪，不叠加相同欠送。匹配建议按明确同客户订单号优先、原交期、建立时间；展示整体分配并允许管理员调整，实际送货仍绑定原订单，不偷换新单和旧单账。

草稿只预关联，不核销；发货原事务按实际数量登记，取消/受控改版原事务精确恢复，可重复请求但不可重复扣减。首页及送货入口显示剩余、最早交期与原因；可补送仅由合资格完整成品及本单预占计算，排除冻结、其他订单预占及未完工片料。客户取消需求仅管理员带原因及审计，不因此改写原订单商业事实。

复用现有天华导入/手机拿货及送货编辑，不重建订单和库存系统。新追踪关联表无历史自动回填。定向测试覆盖300->实际100->剩200、草稿不核销、重复发货/取消、FIFO/同PO提示、客户范围、库存资格、审计事务回滚、重复通知、旧普通送货及天华流程。迁移按完整备份、隔离升降升、原事实摘要、完整性/FK、唯一head及回滚门禁发布；正式页面交管理员人工验收。
