# PRODUCT-STORAGE-BINDING-20260909

## 范围
按老板本轮要求统一常用箱与货架产品卡的默认成品位置配置；允许区域级或正式货架层格级选择；客户默认成品区域优先，其次产品绑定，均无配置时保留一楼待归位规则。解除只取消默认配置，不移动现有库存。产品卡第一行编码、第二行客户简称和数量，明细右对齐。修复生产备注保存闭环。

## 不变量
以已发布地图和正式 location_id 为准，保留地图及草稿。权限、客户范围、版本、幂等、事务、审计、位置策略和容量校验不得绕过。同格同款合并展示，底层批次、来源订单和流水保留。历史生产快照不回写，未收料任务通过既有同步入口更新；新任务使用最新备注。旧固定拣货/扫码拿齐、集货分离规则保留。

## 验证与边界
单代理，独立候选分支；不配置任何正式产品、不移动或修正历史数量。验证配置读写和冲突、失效位置、客户优先、默认回退、同格汇总、备注往返、生产快照冻结、前端构建。涉及新 schema 时完整执行隔离迁移往返及正式备份发布门禁。实体手机和打印验收单独标记。
