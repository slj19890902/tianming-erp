# 货架橙色外框、邻架吸附与方向键

老板要求直接实施：货架四周橙色视觉外框；拖近其他货架自动吸附；重设计货架、货位、区域短按/长按方向键。

方案：默认短按10mm；按住350ms后按时间连续移动（100mm/s），持续1.5秒后300mm/s；Shift精调为短按1mm/长按20mm/s。不依赖操作系统键盘重复频率，不按重复事件突然跳10mm。松键停止并保存一次；失焦/切换选择停止，输入框和修饰快捷键不移动地图。键盘精调不触发磁吸。

邻架吸附仅作用于拖动货架、同向/反向/正交摆放的旋转外框边缘，距离在120mm内，沿边有相邻关系；不隔空跨图吸附、不自动改角度、吸附候选不得新增与其他货架重叠。Alt临时关闭。保留原位置/角度、权限、锁定、冲突和保存/应用流程。

独立worktree codex/rack-snap-keyboard-20260908，从实时正式0b4101f2d开始；不调整正式地图、草稿、库存或身份。定向几何/键盘事件测试与构建、Chrome检查及正式发布门禁；真实操作由现场确认。
