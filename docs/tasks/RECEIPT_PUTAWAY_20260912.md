# 收料自动入位与生产归位

老板于2026-09-12确认实施并发布。

## 已确认规则

- 订单用途按原冻结换算形成成品/套件，采购备库仍保留原料或半成品数量性质。
- 产品固定层格优先，其次产品指定区域，最后一楼待入库区。无效固定格退回待归位，显示原因。
- 一楼待入库区允许多批共存，规划容量只提醒，不因空位数阻断收料。
- 常用箱支持楼层、区域、货架、层格维护及取消。改变默认位只影响后续入库，不搬动现存库存。
- 管理员首次盘点入架且未配置时记住主位；已有配置或多位冲突不自动覆盖；取消后不得下次盘点又自动恢复。
- 生产当前库位第一行：绿色自动入位、黄色待归位、蓝色人工归位；以批次来源和移动流水判定，混放不能用单色误报。
- 保留数量、预占、批次成本、同键重放/异载拒绝、版本、客户权限及审计原子性。
- 正式浏览器由管理员人工验收。
