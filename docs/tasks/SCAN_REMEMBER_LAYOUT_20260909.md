# SCAN-REMEMBER-LAYOUT-20260909

目标：扫码页使用现有remember_me安全会话30天免登录选项，不存储明文密码，不改变其他登录入口的默认时长；公用手机可取消，保留注销及改密/停用失效。扫码页左侧编码、产品名称、规格，右侧客户、实时数量，英文计量单位中文显示；订单仍按需读取。

边界：权限和客户范围不变，不向未登录者泄露客户/库存；同一浏览器同一公网域名内记住登录，跨应用浏览器不承诺共享Cookie。产品数量和单位只改变显示，不改库存事实、地图、绑定或生产。

验证：30天Cookie及auth_version失效的既有认证定向测试；扫码只读范围回归、单位映射/HTML转义、Chrome手机窄屏溢出与登录payload检查；NAS回执记录实体手机待验收。
