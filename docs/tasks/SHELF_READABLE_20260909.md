# 货架可读正视图与余量订单联动

## 老板确认的目标

按 20260908 货架三类正视图设计实施并推送。手机 ERP 盘点优先显示产品名称、规格、实际数量；客户及存货编码为次要识别信息，送货仍保留。任务不得缩为单纯字体修改。

## 闭环与验收矩阵

1. 模具：一实物一条目录、横向可读、关联多产品不复制实物；搜索高亮层格，不伪造格内排位。
2. 单品纸箱：同格同客户正式产品按规格/材质/单位聚合展示，保留批次；混放格逐款列出。移动/盘点以正式批次和位置为准。
3. 时间与订单：明确入库日期精度、最近真实送货、来源订单/占用订单/送货记录；不得按名称猜关联或显示假日期。
4. 手机：名称、规格、实盘数量优先；楼层/区域/货架/层格导航与返回上下文保持，窄屏不压缩或旋转正文。
5. 余量：显示同款其他位置；接通现有成品库存候选、受控预占和净生产/报料计算；不足、重复分配、来源追溯、订单不超送场景验证。不得另造库存账或覆盖已冻结采购。
6. 验证/交付：权限、客户范围、单位、数量、状态、版本、幂等、事务回滚保护；Chrome 桌面/窄屏验证；构建引用、测试、差异、正式基线核对；提交推送并按适用发布规则交付。
