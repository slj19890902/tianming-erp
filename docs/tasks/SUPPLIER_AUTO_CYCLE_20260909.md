# 供应商到期自动草稿与改期重算

范围：用户当前请求中的最小自动对账闭环。供应商已有每月1–31日设置，截止日全天结束后自动生成草稿；正式服务启动和每小时执行，重复运行不重复生成。改期重算当月现有未确认草稿，零来源时保留零金额新修订；旧单和旧明细不删除。未创建的当月账单仍等待周期结束。

安全：系统操作不冒充管理员；事务包含审计。后台不替换人工核对或调整过的草稿；已确认/开票/付款记录不变。历史来源不完整仍阻止生成不完整应付，不将采购用途成本当供应商应付价。测试/UAT不自动启动任务。

验证：自动化2测试（含截止日、重放、旧版保留、审计失败回滚、人工核对保护、改期及零金额）；相邻P1-149 15测试通过。无migration。实体/Chrome人工验收未执行。

历史材料成本尚未完成：165个去重缺口批次中122旧完工、40无来源标识、1补库存、2外购实收，均未找到当前有效正式采购实收用途分配。后两批已有外购采购事实，需要接入独立外购成本来源，不能伪造纸板实收外键。其余继续按稳定ID追溯，未判定全部需要人工补录。既有批准19条材料成本冻结不重复写入；本候选不填造历史价格、数量、余额。

完整证据链：供应商有效采购价合同（单位、币种、税费）→实际收料材质/数量及冻结价→用途/批次换算→实际出库绑定→材料成本冻结。供应商应付只需真实采购实收价格链；销售月报材料成本还需要后续批次出库链，二者不能混同。
