# 供应商付款三步简化

用户同意上一轮审核的下一步，仅实施供应商付款最小闭环。参考金蝶精斗云的应收应付分区与Zoho Books供应商单据/付款分离，非照搬或替换ERP。核对账单、发票、实际付款按蓝/青/橙分步显示。收货与历史折叠；无权限不增加输入；未确认不显示误导剩余0。付款余额算式区分总欠款与发票可付限额。

不改变后台计算/写入API/幂等/审计/确认/权限/发票上限；不补历史来源、价格或余额。本轮不重做客户收钱、日常费用等其他页面。

定向验证：tests/test_supplier_payment_simple_ui.py、tests/test_supplier_credit_first.py；供应商Vue模板用正式内置Vue编译器编译（Node下实体解码不作DOM验证）。无migration。正式截图另记发布回执，不用模板编译冒充现场验收。
