# WAREHOUSE-MORE-MENU-20260911 仓库“更多”菜单遮挡修复

## 现场问题

仓库页点击“更多”后，下拉内容被顶部工具栏裁掉，后续菜单项无法看见或点击。

## 最小闭环

- 只修复仓库顶部“更多”菜单的可见层级和裁剪问题。
- 展开菜单必须完整覆盖在地图上方，所有现有选项可见、可点击，并保持桌面与窄屏布局可用。
- 增加隔离页面布局回归，覆盖嵌入仓库页面的真实工具栏样式组合。
- 构建正式前端资产，按普通 UI 发布流程同步上线并交管理员人工验收。

## 不变量与禁止范围

- 不增删菜单功能，不改变权限、客户范围、操作资格或按钮行为。
- 不修改地图、区域、货架、货位、库存数量、批次、成本或业务数据。
- 不新增 migration，不导入模拟布局，不执行正式页面自动点击验收。

## 验收

1. 嵌入式仓库工具栏的纵向溢出不再隐藏。
2. “更多”展开后最后一个菜单项仍在视口内，点击命中菜单自身而非地图。
3. TypeScript、Vite 构建、定向前端测试和发布安全门禁通过。
