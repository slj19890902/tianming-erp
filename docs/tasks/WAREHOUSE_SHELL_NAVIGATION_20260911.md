# 仓库入口返回 ERP 主框架

## 目标

- 仓库地图只保留“库存台账”入口，删除地图顶部重复的“库存成本”。
- 库存台账内继续保留“库存成本”。
- 从库存台账点击“盘点上架”，以及从库存成本点击“返回仓库”时，进入带左侧业务中心的 ERP 仓库页，不再打开独立全屏仓库。

## 边界

- 不删除库存成本功能、权限或接口。
- 不修改地图、货位、库存、批次、成本和订单事实。
- 正式页面发布后由管理员人工验收，不执行自动点击验收。

## 验收

1. 仓库地图顶部只有“库存台账”，不再显示并列的“库存成本”。
2. 库存台账仍可打开“库存成本”。
3. 库存台账点击“盘点上架”后，左侧业务中心仍存在，内嵌仓库直接进入盘点模式。
4. 库存成本点击“返回仓库”后，回到带左侧业务中心的仓库页。
