# YL 000204 单品误显示 BOM 与常用箱漏保存

## 现场与目标

新建驿力 Z.001.000204 订单被页面显示为 BOM 组合，但常用箱产品 3494 为普通 A1/0201 箱，`is_composite=false`，无主档 BOM 子件。另有常用箱部分字段修改后主保存按钮提示“未检测到可保存的变化”。目标是单品订单按单品展示，真实 BOM 仍展示组件；常用箱所有主表单字段的编辑都进入保存预检，不能静默丢弃。

## 证据及范围

- 正式只读接口：订单 9792 / 明细 10648 仅有一条自指 `GRAPH-3494` 计算节点；生产任务 856 为独立产品任务；主档 BOM 接口组件为空。
- 2026-10-16 19:07 的正式只读隔离副本：在用常用箱 3812 款；非组合却有主档子件 0 款，组合却无主档子件 0 款；旧订单 10592 也含单条 `GRAPH-3494` 自指节点。
- 前端 `hasBomComponents` 只看快照数组非空；普通产品的生产图会合法生成自指节点。主保存入口仅凭 `masterLocalChanges` 判断是否预检，而字段清单未覆盖 `_productFormSaveFields` 的所有持久化字段。

## 合同及边界

- 不删除、重写订单 BOM 快照或生产图；不修改订单、库存、成品、BOM 主档、正式数据库。
- 仅修正页面业务 BOM 呈现和主保存条件。真实子件仍可核对、编辑和追溯，历史冻结事实不按现主档覆盖。
- 用户明确补充的“几模”在 `sheet_cutting_settings` 内，原主保存变更清单漏列它；“位置”有独立的版本化保存接口。主保存应识别几模编辑并在位置有修改时调用现有位置保存接口，失败保留编辑，不声称全部已保存。
- 保留权限、版本、预检、保存结果未知、审计与后端校验。默认位置保留独立保存入口；主表单保存也应采用改过的位置，并说明它只影响以后自动入位。
