# 驿力 000204 送货单误列为 BOM 配套组件

## 现场与目标

正式送货单 154 的 Z.001.000204 在客户打印预览中重复出现：一行 50 只父产品，另一行 50 个“配套组件（不另计价）”。目标是普通产品仅打印一条真实送货明细，单位与数量沿冻结送货记录；真正含子件的 BOM 仍按冻结交付方式打印。

## 证据与原因

- 正式只读库：产品 3494 `is_composite=0`、普通开槽箱、主档子件数 0。送货单 154 仅有一条当前有效的 000204 送货明细，关联订单明细 10592，数量 50、单位“只”。
- 订单明细 10592 只有一条 `GRAPH-3494` 自指生产节点，它是生产图的根，不是 BOM 子件。订单页 v652 已隐藏这种内部根节点。
- 送货单 `_delivery_kit_metadata` 和列表快速投影仍把“存在任意 BOM 快照”作为客户可见 BOM，进而把自指根列为套内组件。打印接口的 `customer_document_rows` 据此重复添加附行。

## 范围与不变量

- 只改送货单及客户打印的展示投影，保留真实订单快照、生产图、库存预占、送货数量、价格、财务和历史冻结事实。
- 不能按当前常用箱主档重写历史订单；用订单快照区分仅有自指生产根与真实子件。真实 BOM 即使有图根，仍保留原组件及冻结交付模式。
- 普通 000204 的正式预览应只有一条 50 只，且无“配套组件”附行；真实 BOM 的父件/子件打印回归必须保持。
- 在隔离数据库副本完成定向回归后，按正式发布流程串行上线；不通过页面自动创建或发送送货单。
