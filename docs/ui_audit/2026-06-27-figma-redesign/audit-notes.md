## 审查范围

- 正式运行地址：`http://127.0.0.1:8000/`
- 桌面基准：1440 × 900
- 手机基准：390 × 844
- 目标：为后续 Figma UI 重设计建立当前运行态证据

## Step 01 登录页

- 截图：`01-login.png`
- 健康度：基本可用，但不满足长辈友好目标。
- 优点：入口单一，登录动作明确，没有多余导航。
- UX 风险：品牌说明、辅助文字和“忘记密码”字号偏小；缺少标准/大字模式入口；关键按钮高度不足以覆盖大字模式目标。
- 可访问性风险：低对比灰色说明文字对老花眼用户不友好；仍需键盘焦点、读屏标签和实际对比度检测。

## Step 02 手机来料未登录态

- 截图：`02-mobile-incoming-logged-out.png`
- 健康度：严重异常。
- UX 风险：390px 宽度下标题、登录失效提示和按钮被压缩成逐字纵排，页面主体基本不可操作。
- 可访问性风险：页面 viewport 禁止用户缩放，与老花眼和现场人员需要放大的目标冲突；红色提示区域点击与阅读空间过窄。
- 建议：移动端改为单列卡片结构，允许缩放；标题、状态、返回登录和刷新按钮分别占完整行；主要按钮高度至少 52px。

## 当前阻塞

正式页面需要现场账号登录。旧默认密码已经失效，当前会话没有获授权的登录凭据。需要用户在已经打开的本地浏览器中手动完成登录，之后才能继续捕获首页、客户、常用箱与材质、订单、报料、来料、送货回单、财务和系统设置等运行态界面。

## 综合结论

- 手机来料页在真实登录态和真实待收料数据下仍然严重错位，属于 P0 问题。
- 桌面仓库来料、送货回单、新建订单在 1440px 下仍依赖横向滚动。
- 订单、客户、材质等列表的行内按钮过多，危险操作缺少收纳。
- 全局缺少标准 / 大字模式。
- 状态颜色和模块颜色尚未形成跨页面固定语义。
