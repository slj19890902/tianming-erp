## 操作结果

- 邮件先选一份单据再核单，突出产品、数量、单价和金额；订单号、日期和识别过程放在辅助位置。保留原草稿对象、价格权限、保存门禁。库存弹层先显示拟用数量、位置与未覆盖量，成品安排和位置不重复；半成品、原料分别查看规格、压线、材质、数量和候选资格。
- 常用桌面列表按视口容量分页；来料历史切页先清空旧数据并显示加载，失败可重试，旧请求不能覆盖新页。说明改为点击展开，业务错误和必要确认仍明确显示。已报料点击供应商查看实际关联采购单，沿用单款撤销与下游数量/状态保护；共享来源不能绕过原撤销门禁。
- 组合备库按有效配方一起安排，冻结每套用量与子件身份，预占/完成/取消为同一事务。分开实收的子件保留独立库存账，整组选择共同位置，保留实际产出核对。楼层、区域、货架/货位逐级选择，仍遵守已发布仓库地图资格。独立子件不能绕过整组撤销。待生产保留并区分订单生产与备库生产。
- 财务按办理事项分区，费用、固定费用、加工设置等独立显示，详情弹层分页；完工历史与库存去向统一布局。主要操作无需向下滚动才能找到，不用隐藏必要数据换取表面整洁。

## 205 数量边界
