# N081 Phase 0：库存盘点与首次数据入库就绪性只读审计

日期：2026-07-22

权威候选基线：`origin/factory-current-baseline@c5cffa2123973b3f30b74be7f6dc198d1f070210`

审计分支：`codex/n081-inventory-count-roadmap-20260722`

## 1. 结论

N081 不应继续按“先统一地图和栈板，再直接把盘点草稿确认成正式库存”的原顺序实施。

当前代码已经具备正式库存批次、客户专用/通用成品、库存流水、预占、栈板、三楼位置和 N035 手机盘点。真正影响近期库存盘点和数据入库的缺口是：

1. N035 只盘点已经存在的成品库存批次，不能登记现场发现但 ERP 尚无批次的账外库存，也不能盘半成品。
2. 楼层、仓库、区域仍主要是 `warehouse_locations` 上的整数/字符串字段；只有三楼有独立布局表，尚未形成所有楼层共用的空间主数据。
3. 当前有逐笔手工入库，但没有“导入文件 → 原文保留 → 匹配校验 → dry-run → 小批确认 → 正式入账”的首次盘点导入链。
4. 现有 `source_type` 表示库存取得方式，`FinishedGoodsInventoryDetail.is_general/owner_customer_id` 表示归属；原任务书把客户备库语义放到 N080-B，晚于 N081 正式盘点入账，存在先入账后返工分类的依赖倒置。

因此，近期主线应改为：

```text
空间主数据收口
→ 库存归属与盘点字段口径冻结
→ 账外库存导入草稿
→ 3～5 个成品栈板 + 2～3 个半成品栈板试盘
→ 按区域分批正式入账
→ 再做最低库存、备库生产、直接出库和送货找货
```

## 3. 必须分开的两类盘点

### 3.1 已有账库存复盘

继续复用 N035：

```text
选择库位和已有批次
→ 输入实盘数量
→ 提交后库存不变
→ 管理员审核
→ 只对差异写 adjust 流水
```

其门禁继续保持：快照漂移拒绝、实盘数不得低于已预占数、审核幂等、已审核事实不可修改。

### 3.2 账外库存首次建账

新增 N081-B 盘点导入草稿，不得伪装成 N035 的“已有批次数量调整”：

```text
下载模板 / 手机逐板录入 / 导入 Excel 或 CSV
→ 保存原始文件哈希、原始行号和原文
→ 匹配客户、产品/材质、库位和栈板
→ 标记新增库存或关联已有批次
→ dry-run 差异与错误清单
→ 人工逐行/逐批确认
→ 小批事务创建正式批次、栈板投影和 manual_in 流水
```

确认前不得创建 `inventory_lots`、不得改变库存余额、不得预占或抵扣订单。

## 4. 首次盘点导入字段口径

每行至少保留：

```text
导入批次号、源文件 SHA-256、原始行号
盘点日期、盘点人
楼层、仓库、区域、库位编码、稳定 location_id
栈板号（可空；确认时自动生成）
库存类型：成品 / 半成品
客户原文、客户 ID
存货编码/产品原文、产品 ID
数量、单位（箱 / 张）
取得来源 = stocktake
归属：客户专用 / 通用
实际入库日期原文、日期可信度：exact / estimated / unknown
材质、楞型、长宽、片料类型（半成品适用）
匹配状态、错误码、人工决定、备注
```

规则：

- 成品正式确认前必须匹配现有客户和产品；未知客户/产品只能留在草稿。
- 三级厂未加工纸板继续按现有半成品 `sheet_type=raw_board` 口径处理，不在 N081 新建第三套原材料数量账。
- 历史入库日期不明时不得猜日期。技术日期可使用盘点确认日，但必须同时保存 `date_accuracy=unknown`，库存洞察不得把它当作精确库龄。
- 客户备库/通用库存是归属维度；`stocktake` 是取得来源，两者不能共用一个字段。
- 同一文件重复导入、同一行重复确认、同一幂等键改变内容均应拒绝。
- 同一现场实物若已有关联批次，必须走 N035 或明确绑定已有批次，不能再次创建新批次。

## 5. N081 修订后的内部阶段

### N081-0：只读准备

- 工厂只读导出楼层、区域、库位、现有批次、栈板和未定位数据质量清单。
- 确认现场盘点范围、负责人员、区域顺序和停更窗口。
- 生成盘点模板和脱敏模拟样本；不写正式库。

### N081-A：统一空间主数据

- 复用 `warehouse_locations` 稳定 ID，补齐楼层、仓库、区域、用途、地图和编码别名。
- 三楼现有布局迁移为共用地图模型，一楼 A—F、三楼 G—L 使用同一数据源。
- 新库位先“未放置”，地图放置后才可承载正式库存或模具。
- 库位改码保留旧别名；业务外键不随显示编码变化。

### N081-B0：库存归属与日期口径

- 在盘点导入前冻结取得来源、客户专用/通用归属、库存日期可信度和半成品分类口径。
- 只补盘点必须的 N080-B 基础语义，不提前实现备库生产、直接出库或欠送。

### N081-B1：账外库存导入草稿

- 支持模板、文件哈希、原始行、匹配、错误导出、dry-run、幂等和人工确认。
- 草稿可反复修正；提交后保留不可变快照；拒绝项不得写正式库存。
- 文件上传必须使用 P0-B 的私有上传与类型/大小校验；P0-B 未进入发布基线前，工厂不得启用文件导入。

### N081-B2：小范围试盘

- 先录 3～5 个成品栈板和 2～3 个半成品栈板。
- 在隔离副本验证后，再在工厂备份和明确授权下选择一个区域试盘。
- 核对客户、产品、数量、库位、栈板、流水、重复导入和订单候选；通过后才进入分区盘点。

### N081-B3：按区域分批入账

- 按区域建立不可变批次清单，每次只确认一个小批次，默认不超过 100 行。
- 每批先 dry-run；确认事务全成或全败；失败保留现场，不自动继续下一批。
- 每批后核对批次/流水/栈板/库位数量、外键、重复键和错误行，并由用户人工验收。

### N081-C：移动、拆板与复盘收口

- 整板移动复用现有版本和幂等事务。
- 部分数量移动通过拆板产生新栈板并保留来源；不得直接改栈板显示数量。
- 已入账库存后续复盘回到 N035；盘亏盘盈只写调整流水。
