## 为什么使用 MDF 当前库

当前 Windows 登录可读 SQL Server 中已经挂载的 `BoxDB20` 数据库，但没有 `sysadmin/dbcreator` 权限，不能把 `.bak` 恢复成临时库。

同时，当前 MDF 里的客户数据比最新 `.bak` 更新：

```text
Customers 最大更新时间：2026-04-27 10:03:37
BAK 备份时间：2026-01-30 16:00:17
```

因此本次以当前挂载的 `BoxDB20.mdf` 作为最新源数据。

## 已新增的 ERP 表

### `company_file_index`

用途：

保存本机和历史资料中的公司文件索引，包括报价、合同、图纸、图片、对账单、订单等文件路径。

字段大意：

- customer_id
- source_path
- file_name
- file_ext
- file_size
- modified_at
- source_root
- category
- keywords
- inferred_customer_name

### `legacy_ruida_customers`

用途：

保存瑞达 `Customers` 原始客户字段，便于以后查漏、合并、追溯。

包括：

- 瑞达客户 ID
- 客户编码
- 简称
- 全称
- 电话、手机、传真、联系人
- 地址和备用地址
- 银行、账号、税号
- 账期、开票、毛利限制等字段
- 原始 JSON

### `legacy_ruida_orders`

用途：

保存瑞达历史订单主表，暂不混入当前生产订单表。

### `legacy_ruida_order_items`

用途：

保存瑞达历史订单明细，包含客户单号、款号、规格、材质、数量、价格、供方、工艺等历史字段。

## 注意事项

1. `legacy_ruida_*` 表是历史源数据表，不要直接当作当前生产订单操作表。
2. 当前订单表 `orders` 只用于新 ERP 产生的新订单。
3. 历史订单查询页面应从 `legacy_ruida_orders` / `legacy_ruida_order_items` 读取，但必须分页和条件查询。
4. 文件索引只是路径和分类，不是把所有图片/PDF内容塞进数据库。
5. 如果未来服务器上不挂载 K 盘，应把整个 `carton-erp` 目录复制到服务器数据盘，并保持 `data/carton_erp.sqlite3` 在服务端持久化目录内。
