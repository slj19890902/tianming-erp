目标不是让办公电脑保存数据库，也不是让办公电脑长期运行后端程序。

```text

办公电脑：只用浏览器访问 ERP 网页
```

## Docker 启动方式

在服务器或 NAS 上进入目录：

```bash
cd /path/to/docker/carton-erp
docker compose up -d --build
```

容器端口：

```text
18081:8000
```

启动后浏览器访问：

```text
http://服务器IP:18081/
```

如果部署在极空间，访问：

```text
http://极空间IP:18081/
```

## Docker Compose 内容

当前 `docker-compose.yml`：

```yaml
services:
  carton-erp:
    build: ./app
    container_name: carton-erp
    restart: unless-stopped
    environment:
      CARTON_ERP_DB_PATH: /data/carton_erp.sqlite3
    ports:
      - "18081:8000"
    volumes:
      - ./data:/data
```

## 当前代码中的数据库保护

`main.py` 已改为：

- 默认数据库路径指向 NAS。
- 支持 `CARTON_ERP_DB_PATH` 覆盖。
- 如果数据库目录不可访问，程序直接报错。
- 不会在 F 盘本地自动生成新的正式数据库。

## 上线前建议

1. 确认服务器或 NAS 固定 IP。
2. 确认 18081 端口没有冲突。
3. 修改默认账号密码。
4. 建立自动备份策略。
5. 确认多人同时使用时是否仍用 SQLite。
6. 如果多人频繁同时写入，建议升级为 PostgreSQL 或 MariaDB。
